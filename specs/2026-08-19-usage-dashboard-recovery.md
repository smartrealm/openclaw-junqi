# 用量仪表盘恢复规格

## 上游契约

- OpenClaw `usage.cost` 返回日期范围内的聚合用量与估算费用。
- OpenClaw `sessions.usage` 返回按会话、Agent、模型和日期聚合的用量。
- Token 与费用是不同事实。只有模型配置价格且供应商返回用量元数据时，OpenClaw 才能估算费用；缺少价格时仍可展示已记录的 Token。

## 验收条件

1. 智能体卡片只能渲染真实 React 图标组件，不得把 JSX 源码、组件属性或占位字符串显示给用户。
2. 图标类型可以由 Agent ID 稳定派生，但不得影响 Agent 身份、名称、路由或运行状态。
3. 仪表盘在部分调用未定价且至少有两个日期的 Token 记录时，默认展示每日 Token 趋势。
4. 同时存在已知费用和 Token 时，用户可以在“费用”和“Token”之间切换；标题、图例、坐标轴和提示必须随指标一致变化。
5. 未定价调用不得记为已知零费用，也不得根据供应商名称或本地假设补造价格。
6. 只有一个日期的 Token 记录时显示汇总，不绘制虚假的趋势线。
7. 顶栏只保留页面身份和主要操作；业务错误必须在所属诊断区域完整展示。

## 未验证边界

- 未在真实多供应商、混合已定价和未定价调用的数据集上完成图表视觉验收。
- 未验证所有供应商是否都会返回完整的输入、输出和缓存 Token；界面只消费 OpenClaw 已聚合的字段。
