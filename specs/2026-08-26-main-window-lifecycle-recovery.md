# 主窗口生命周期恢复规格

日期：2026-08-26

## BUG-WIN-01 · 红色关闭没有结束整个应用

### 当前行为

主窗口关闭请求直接销毁窗口。应用因托盘或其他窗口继续运行时，所有恢复入口只能查找已不存在的 `main` 窗口并静默结束。

### 目标行为

- 主窗口红色关闭请求先阻止默认窗口销毁，再明确结束整个应用及其附属窗口。
- 黄色最小化、应用级隐藏和辅助窗口返回主界面继续保留主窗口恢复语义。
- 恢复入口在主窗口缺失时返回或记录明确错误，不伪报恢复成功。

### 验收条件

- [ ] 原生关闭和前端 `close()` 均请求整个应用退出，不遗留宠物、托盘或 Gateway 子进程。
- [ ] 黄色最小化后可通过 Dock、托盘、单实例和萌宠入口恢复同一个主窗口。
- [ ] 主窗口关闭处理不会阻塞托盘退出或系统退出。
- [ ] 主窗口缺失时恢复函数返回结构化错误。

## BUG-WIN-02 · 恢复顺序和失败语义分散

### 当前行为

各入口分别调用 `show`、`unminimize` 和 `set_focus`，调用顺序不一致且多数忽略错误；macOS 应用级隐藏没有统一恢复。

### 目标行为

- 所有入口调用同一个 Rust 主窗口恢复函数。
- macOS 先显示应用，再取消窗口最小化、显示窗口并设置焦点。
- 任一步骤失败都带有精确步骤信息；事件回调将错误写入诊断日志。
- 托盘切换在窗口最小化时执行恢复，在普通可见状态下执行隐藏。

### 验收条件

- [ ] Dock、单实例、托盘、萌宠、灵动岛和控制窗口返回入口没有重复恢复序列。
- [ ] 主窗口存在时统一恢复函数成功完成。
- [ ] 主窗口不存在时不会静默返回成功。
- [ ] Rust 定向测试、完整 Rust library 测试、静态检查与生产构建通过。
- [ ] macOS 真实窗口连续交互完成验证；Windows 与 Linux 未实测时明确保留边界。
