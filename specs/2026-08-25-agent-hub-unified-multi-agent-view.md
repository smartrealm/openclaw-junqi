# 智能体中心统一多 Agent 视图规格

日期：2026-08-25

## 目标

Agent、OpenClaw 原生子智能体会话和 JunQi 持久协作运行只通过智能体中心呈现。客户端不得为同一批 Gateway 会话维护第二套独立监控页、轮询、历史解析和空态语义。

## 行为

- 智能体侧栏提供“协作办公室”入口并导航到 `/agents`。
- 智能体中心继续使用办公室、树状、网格和活动视图承载不同投影。
- 原生子智能体只依据已投影的 Session 类型和 Gateway 运行字段展示，不以页面私有正则重新解释 Session key。
- 持久协作运行继续由协作插件结构化能力与运行记录投影，不与普通子智能体会话混为同一状态。
- 无数据时由智能体中心的统一空态、配置入口和错误边界处理，不注册独立 `/agents/live` 页面。
- 树状视图连线依据真实卡片矩形和完整滚动内容坐标计算，换行、滚动和尺寸变化后不得脱离目标卡片。
- 装饰性连线动画遵守系统减少动态效果偏好。

## 验收

1. 路由树包含 `/agents`，不包含 `/agents/live`。
2. 导航、版本特性注册表、语言资源和标签归属不再引用 `liveAgents`。
3. 被替代的 `MultiAgentView` 及其私有轮询、历史解析和空态被删除。
4. 定向测试、TypeScript、完整测试、lint、build 和差异检查通过。
5. 所有被运行时代码引用的新增模块与测试都进入同一 Git 变更集。
