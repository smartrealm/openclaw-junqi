# 工作区布局与结构化会话记录规格

## LAYOUT-01 · 工作区页面统一适配

当前：主要页面使用互不一致的固定最大宽度。

目标：数据型和管理型页面外框使用统一的全宽弹性契约和响应式内边距，不按具体页面写死画布上限。

验收：

- 宽窗口中页面使用侧栏以外的可用宽度，不产生由页面上限制造的大块留白。
- 窄窗口保持单列或既有响应式断点，主要操作可达。
- 阅读正文、对话气泡和弹窗的局部可读宽度不被强制拉伸。

## TRACE-01 · 动态结构化展示

当前：长工具结果的截断字符串遮蔽了仍存在的原始结构化内容。

目标：根据实际数据递归识别对象、数组、内容块、JSON 字符串和外部内容包络，不按工具名或业务字段硬编码。

验收：

- 超过紧凑展示上限的真实文本块数组仍以结构化字段展示。
- 嵌套 JSON 字符串递归解码，普通文本与畸形 JSON 保持原样。
- 外部不可信内容提示和原始载荷折叠区继续存在。
- 工具气泡继续使用有界输出，不因原始记录展示扩大主会话渲染负担。
- 原始记录标题栏提供复制图标；工具记录复制已加载的原始载荷，普通消息复制原始正文，无记录时不可操作。
- 复制按钮具备可访问名称、键盘焦点，以及已复制和失败反馈。
