# 钉钉桌面工作台 UI 规格

## 目标行为

1. 页头只承载视图标题、当前真实状态、DWS 当前身份和刷新动作，视觉规格与相邻桌面工作区一致。
2. 工具页不再维护独立筛选侧栏；搜索、业务域、读写范围和结果数量属于同一目录工具栏。
3. 工具项以名称和说明为首要信息，业务域只在分组标题出现一次；效果、风险和 Session 明确拒绝作为次级状态。
4. 每个工具项只有一个可聚焦选择入口，并通过 `aria-current` 表达当前选择。
5. 工具详情中的当前 Profile、参数契约、参数错误、风险提示和执行动作按任务顺序排列；主执行动作在详情滚动时保持可达。
6. 技术 ID、DWS 路径、schema 摘要、调用原始结果和审计证据使用渐进披露，不与日常任务正文争夺层级。
7. 小于宽桌面断点时，目录和详情不并排挤压；选择工具后显示详情，关闭详情后返回目录。
8. 工具、接入和审计视图使用同一标题、正文、说明、控件高度、圆角、边框和状态色层级。
9. 亮色、暗色和其他 Aegis 主题只消费现有语义 token，不新增业务硬编码颜色。
10. 所有新增固定文案在简体中文、繁体中文和英文资源中保持同一键集合。

## 验收条件

- 工具表不再出现重复业务域列，目录项直接显示 DWS 或插件返回的工具说明。
- 鼠标或键盘激活工具项都调用同一选择行为，选中项具有可访问状态。
- 筛选条件激活时提供清除入口，未激活时不常驻无意义按钮。
- 详情关闭按钮在宽窗口折叠检查器，在窄窗口返回目录；两种情况下目录都保持原筛选和选择状态。
- 主执行按钮在详情底部固定区域可达，禁用原因在按钮附近显示，加载状态不伪造完成。
- 审计列表的默认正文不铺开 Session、run、tool call、DWS 路径、核验路径和资源 ID；有这些证据时可以通过键盘展开。
- loading、error、empty、disabled、focus-visible 和选中状态均有明确视觉与语义反馈。
- `corepack pnpm lint`、定向测试、`corepack pnpm test`、`corepack pnpm build` 与 `git diff --check` 通过。

## 插件兼容性验收

1. 固定钉钉插件元数据必须包含从插件包派生的插件 API 范围和最低 Gateway 版本，并与归档内 `package.json` 字节一致。
2. 当已核验 Gateway 低于兼容下限时，Rust 安装命令在调用 `openclaw plugins install` 前失败关闭。
3. 业务台将确定不兼容显示为 OpenClaw 升级任务，复用共享官方更新面板，不显示重复安装动作。
4. 兼容性无法解析时保留未知语义；不得仅依版本文本猜测安装已成功。
5. 安装失败只在当前对话框就地呈现，不再向页面就绪面板复制同一错误。
6. 用户确认安装固定归档后，非交互安装必须显式接受插件及其依赖声明的能力与安装策略警告；本地归档不得携带只适用于 npm registry 安装的 `--pin`，归档固定性继续由已校验哈希和版本元数据保证；OpenClaw 的阻止规则和真实失败不得被绕过。
7. 命令失败时必须跳过前置的全局配置警告并显示真实失败原因；不得把其他插件的重复标识警告描述为钉钉安装结果，也不得修改其他插件配置。

## 未验证边界

- 目标租户的真实工具数量、工具说明长度和权限错误分布。
- Windows、Linux 的系统字体、WebView 缩放和高对比度模式。
- 正式签名安装包中的触控板、屏幕阅读器和窗口恢复行为。
