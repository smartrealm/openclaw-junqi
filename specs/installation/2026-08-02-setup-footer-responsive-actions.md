# 首次安装底部操作区响应式修复

## 当前行为

首次安装的储存位置步骤在加载或确认期间使用动态长度的主操作文案。窄窗口同时存在回退、次要和主操作时，横向布局没有为操作区提供稳定的窄屏分区，可能产生视觉重叠。

## 目标行为

- 小于 `sm` 的首次安装窗口中，回退区与主操作区按行分隔。
- 主操作在窄屏占满自己的操作行，加载文案不与回退或次要操作争夺水平空间。
- `sm` 及以上保持既有左右操作布局。
- 不改变储存配置、迁移、回退和完成推进的状态或 IPC 契约。

## 验收

- 回退到储存步骤后，确认当前储存位置的加载按钮不与其它按钮重叠。
- 带较长本地化加载文案时，按钮文字保持可见且操作区不发生覆盖。
- `src/components/setup/SetupFlowPanels.test.tsx`、TypeScript 检查和构建通过。
