# 首次启动往返导航修复规格

日期：2026-08-08

状态：已实现并通过本机 macOS 验收。根因见[审计记录](../../docs/installation/setup-round-trip-navigation-audit-2026-08-08.md)，证据见[验证记录](../../docs/installation/setup-round-trip-navigation-validation-2026-08-08.md)。

## BUG-SETUP-01：步骤页面生命周期与动效冲突

### 修复前行为

步骤切换使用退出与进入页面并存的动画。旧页面在状态已经切换后继续挂载 240 毫秒。

### 目标行为

状态切换立即卸载旧页面。新页面根据前进或返回方向执行小幅透明度和水平位移动画；减少动态效果偏好下立即呈现。

### 验收条件

- 页面树任意时刻只有当前步骤页拥有运行生命周期。
- 下一步从右侧轻量进入，返回从左侧轻量进入。
- 动效不延迟 Store 导航，也不保留退出页的指针或异步状态。

## BUG-SETUP-02：环境动作状态不可见

### 修复前行为

环境页按钮只根据 Docker 展示状态禁用，处理器还可被私有引用静默拦截。

### 目标行为

环境页的导航和重新检测动作具有一个对 UI 可见的忙碌状态。原子单飞保护与按钮禁用使用同一状态转换。

### 验收条件

- 环境动作进行中时，上一步、重新检测和下一步均不可重复触发。
- 返回环境页后动作状态为可用，第二次下一步能够再次进入数据位置。
- 处理器拒绝重复动作时，界面已经呈现禁用或加载状态。

## BUG-SETUP-03：缺少完整往返回归

### 修复前行为

导航、动作锁和动效分别测试，不能覆盖组合故障。

### 目标行为

使用同一行为序列验证环境动作和导航历史：环境下一步、数据位置上一步、环境再次下一步。

### 验收条件

- 修复前的旧锁释放策略或退出页面保留策略不能满足测试契约。
- 导航最终位于数据位置，历史仅包含欢迎页和环境页。
- 环境动作在第二次下一步前处于空闲态。
