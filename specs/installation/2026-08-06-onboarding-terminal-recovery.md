# 新手引导终态恢复规格

日期：2026-08-06

## 验收条件

1. 向导终态 `Done` 不等同于 JunQi 工作台已就绪。
2. Gateway 进程可达但桌面认证连接未完成时，错误文案明确说明连接验证失败。
3. 终态确认超时或会话丢失时不得由当前配置推断或伪造向导完成；只能重新连接并恢复仍存在的官方会话，或重新启动官方向导。全局模型探测不得成为恢复门槛。
4. 重试收到 `wizard not found` 时，客户端不得把它作为最终用户错误；必须依据当前运行时重新恢复或启动官方向导。
5. 模型实时探测只作为独立诊断，不得把无关 provider/profile 的结果解释为当前默认智能体失败；工作台准入遵循 OpenClaw 的 Gateway 与默认模型配置条件。
6. 当已认证 Gateway 明确返回 `openclaw.setup.detect` 方法不存在时，JunQi 不得把方法缺失显示为安装失败，也不得以本地配置伪造完成状态；必须启动同一 Gateway 的官方 `wizard.start`，由其决定既有配置、跳过项或终态。连接、鉴权或畸形响应仍必须失败关闭。
