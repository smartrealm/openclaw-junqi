# 首次启动凭据授权规格

日期：2026-08-07

## 验收条件

1. 当前配置能提供共享 Gateway token 时，启动连接不得读取设备 token 凭据项。
2. 当前配置能提供共享 Gateway token 时，握手返回的设备 token 不得在首屏自动写入系统凭据库。
3. 没有共享 Gateway token 的连接仍可读取已配对的设备 token，并在需要时持久化新的设备 token。
4. 设备私钥持久化在 JunQi 应用私有配置目录，渲染进程不得取得私钥；Unix 文件权限为 `0600`。
5. 会话快照成功后即可进入工作区；智能体列表失败不得阻塞首屏。
