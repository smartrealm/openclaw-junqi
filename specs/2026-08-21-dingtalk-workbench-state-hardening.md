# 钉钉工作台状态收敛规格

## 当前行为

钉钉工作台已经使用 OpenClaw `tools.effective`、`tools.invoke` 和 DWS Profile/schema，但工具详情、空状态、schema 异步请求、Session 切换和 DWS 操作启动仍存在互相独立的本地状态。

## 目标行为

1. 工具目录只表达当前 Session 的可见操作，不表达账号业务权限。
2. 工具详情不重复显示正常目录可见性和未核验的账号权限；明确被拒绝时才显示 Session 拒绝。
3. 每种目录不可用原因具有准确标题与说明；加载中不发布终态空状态。
4. schema 结果必须同时匹配最新请求代次、请求 Session 和请求工具。
5. Session 变化时必须清理工具交互草稿并使旧 schema 请求失效；执行 Profile 变化时清理参数草稿与调用结果，调用期间禁止切换 Profile。
6. DWS 操作从调用 Tauri 前即进入 starting；starting 与 running 共享忙碌门禁。
7. 已结算 DWS 操作的内部事件和终态缓存必须回收。
8. 所有新增或修改的 UI 文案进入现有中、繁、英语言资源，不在业务组件中新增硬编码状态文案。
9. DWS schema 确认有缺失必填参数或参数 JSON 无效时，详情面板必须直接暴露 JSON 输入，不要求用户先发现并展开隐藏区域。
10. 工具表、工具详情、DWS Profile 选择器和插件安装进度的固定控件文案必须来自语言资源；DWS 与 OpenClaw 的动态工具数据和错误不得由客户端猜测翻译。
11. 工作台中的官方文档链接必须经受控桌面外链打开器处理；打开失败时在当前界面反馈，不能静默调用 WebView 打开器。
12. 客户端解析已知的 DWS 参数契约失败时，必须通过稳定错误码映射为当前语言；Gateway 或 DWS 返回的运行时错误保持原始诊断。
13. 同一 Session 已读取的 OpenClaw 官方审计记录在刷新失败时保持可见，并显示该次刷新失败；仅在断开或 Session 缺失时清空旧范围数据。
14. `tools.effective` 的目录可见性不得表示钉钉插件 `allowedAgentIds` 已放行；当前 Session 的运行时探针成功才可标记插件 Agent 门禁为已核验。
15. Session 模型目录必须在独立、固定滚动区域内展示完整 Gateway 投影，包含可见数量、筛选结果数量和可访问的滚动区域；运行参数不得挤占模型目录高度。
16. 业务审计页中的 JunQi 本窗口投影必须按创建时的精确 `sessionKey` 隔离；摘要、筛选和清除不能跨越当前 Session。
17. DWS 运行时身份快照必须同时匹配当前连接、Session 与 `tools.effective` 修订，并且已经结算；刷新期间不能以旧 Profile 保持目录或执行入口可用。
18. 未获 DWS 官方结果 schema 证明的审批记录、任务和实例字段不得被解析、合成或展示为审批轨迹；只保留官方工具原始结果。

## 验收条件

- 旧 schema 晚到时不能覆盖新工具 schema，也不能结束新请求的 loading。
- 从 Session A 切换到 Session B 后，A 的参数 JSON、schema 和调用结果不可见。
- 无 Session、无工具、缺运行时工具、身份失败、Profile 未登录分别显示对应原因。
- DWS start promise 未返回时再次触发不会发起第二次启动请求。
- 工具详情正常状态不出现“账号权限：调用时核验”或“Session：已暴露”。
- 当前 schema 要求参数而参数草稿缺失时，用户无需额外展开高级区域即可编辑 JSON；字段列表仍仅来自当前 DWS schema。
- 切换语言后，工具表、详情和 Profile 选择器的固定控件文案不与旧语言混用。
- DWS 参数契约的本地解析失败以当前语言呈现；Gateway 或 DWS 原始错误文本不被客户端翻译或替换。
- 官方审计已有记录时刷新失败，记录和分页游标保留，失败仅作为列表内提示；断开或 Session 缺失时记录被清空。
- 工具已出现在 `tools.effective` 但当前 DWS 运行时探针尚未成功时，Agent 授权步骤为待核验并给出授权配置入口；探针成功后才显示已核验。
- 长模型目录可滚动至末项，模型和运行参数互斥显示，数量提示与筛选结果一致。
- 切换到另一 Session 后，前一 Session 的本窗口投影、摘要和清除按钮均不可见且不会被清除；官方审计继续由当前 Session 的查询结果单独决定。
- 当前工具修订变更后，旧运行时身份、Profile 与工具目录立即不可用于执行；只有该修订对应的探针结算后才重新发布目录。
- 审批工具原始结果中即使出现未知字段，也不会触发本地审批轨迹、自动二次查询或状态推断。
- 相关行为测试、TypeScript 检查、边界检查、生产构建和 `git diff --check` 通过。

## 未验证边界

- 真实 DWS schema 是否提供足够元数据构建字段级表单仍待上游契约证明。
- 真实 macOS、Windows、Linux 桌面连续操作与视觉验收需要安装包实测。
