# 业务审计与模型选择器状态规范

## 业务审计

- 读取失败不得显示“尚无审计”或其他成功空结果标题。
- 只有官方请求成功且官方记录和本窗口投影都为空时，才显示空结果。
- 错误状态必须保留原因，并提供重新读取入口。
- `INVALID_REQUEST` 下的精确 `unknown method: audit.activity.list` 必须归类为活动审计不支持。
- `missing scope: operator.admin` 与其他权限错误必须保留失败事实，不得通过错误文本、握手通告或本地版本推断为旧活动审计不支持。
- 除官方未知方法结构化响应外，其他错误不得改类。
- 日常 Gateway 连接与协作插件读写不得请求 `operator.admin`。只有高权限 RPC 的短暂独立连接可以请求该 scope。
- 高权限连接收到官方结构化 `MISSING_SCOPE` 或 `AUTH_SCOPE_MISMATCH` 时，必须发布统一授权恢复界面，展示结构化缺失 scope；不得显示裸错误文本、自动重试写操作或断开日常 Gateway 连接。
- 授权恢复界面必须区分“存在待审批设备请求”和“已有设备缺少 scope”：前者可调用官方批准操作并等待原请求重试，后者只能引导用户在 OpenClaw 控制台重新配对或批准相应 scope 后手动重试。
- `audit.activity.list` 被官方判定缺失时，只有不包含 `message`、`direction` 或 `channel` 的运行与工具查询才能重试官方 `audit.list`。
- `audit.list` 返回页必须显式标记为 `legacy`，只作为 Agent 与工具元数据账本展示；不得伪装成新版活动账本，也不得用于消息查询。
- 活动账本已通告但读取失败、旧账本 schema 无效、未授权、断线和其他错误不得回退到 `audit.list`、本窗口投影或本地状态。
- 已有本窗口投影时，官方读取失败不得隐藏本地投影；错误作为非阻断警告展示。
- 官方审计页必须携带其读取时的精确 Session key；当前 Session 改变后，旧 Session 的记录、游标和失败状态都不得继续作为新 Session 的界面状态或失败保留依据。
- Gateway 断开后，同一 Session 的旧账本也不得继续展示；界面立即显示断连，等待连接恢复后的官方重新读取。
- 所有用户可见状态使用简体中文、繁体中文和英文资源。

## 模型选择器

- 模型目录和运行参数必须使用两个明确页签，默认打开模型目录。
- 供应商列表与模型列表必须在模型目录页签内独立滚动。
- 模型目录必须支持按显示名称、别名和完整模型 id 筛选，筛选不会创建或隐藏 Gateway 未返回的模型。
- 运行参数必须使用独立滚动区，不能挤占或裁切模型列表。
- 底部操作始终可达。
- 弹层必须使用共享视口碰撞边界，不能被父级滚动容器裁切或超出桌面视口。
- 共享弹层宿主必须明确为 Tauri 非拖拽区域；Portal 不得因脱离触发元素的祖先树而失去模型选择和滚动交互。
- 布局只使用现有 `aegis-*` 主题 token，并适配窄窗口和有限视口高度。
- Escape、外部点击、禁用、加载和键盘焦点行为保持现有契约。

## 验收

1. 审计请求失败且记录为空时，只显示失败标题和失败说明。
2. 审计请求成功且记录为空时，显示真实空状态。
3. 有本窗口投影且官方请求失败时，投影仍可见并显示非阻断警告。
4. 模型数量超过可见高度时，模型列可滚动到最后一项。
5. 参数数量超过可见高度时，参数区可滚动，底部操作保持可见。
6. 旧 Gateway 返回官方未知方法结构化响应时，界面显示“不支持”；任何权限错误均保留失败而不伪装为不支持。
7. 窄窗口中打开模型弹层时，弹层与全部底部操作仍在视口内。
8. Session 切换后官方审计读取失败时，上一 Session 的记录与分页游标不会显示或保留到新 Session。
9. Gateway 断开时，已读取账本和“加载更多”入口立即隐藏，页面只显示断连失败状态。
10. 旧 Gateway 缺失活动账本且查询仅涉及工具时，页面显示兼容工具账本来源；消息筛选不能调用旧账本。
11. 无边框 Tauri 窗口中，挂载到文档根节点的模型菜单可以滚动并选择未锁定模型，不会触发窗口拖拽。
