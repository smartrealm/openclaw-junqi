# 目标环境证据与副作用链路修复规格

## BUG-01：Node.js 写入必须先取得目标 OpenClaw 契约

### 当前

首次安装以 `LegacyFallback` 的 `*` 解析或安装 Node.js，之后才查询目标 OpenClaw 包的 `engines.node`。

### 目标

首次安装先通过不依赖 Node.js 写入的公共 npm 元数据解析路径取得精确目标包及其 `engines.node`；已有完整 Node/npm 对时，继续使用该对读取用户 npm 配置。任何 Node.js 写入、修复或覆盖只接收已安装包或已解析目标包的准确范围。

### 验收

- `LegacyFallback` 不能进入 Node.js 安装、修复、更新或覆盖函数。
- 没有完整 Node/npm 对时，公共元数据解析成功后才允许安装与目标范围匹配的 Node.js。
- 已有完整 Node/npm 对时，目标包元数据继续使用其 npm 配置来源。
- 无法取得目标包准确 `engines.node` 时，流程在写入前失败。

## BUG-02：DWS 中止不得启动或误报有副作用工具

### 当前

`DwsRunner.run` 在检查或订阅 `AbortSignal` 前启动 DWS 子进程。预先中止的调用可能执行写操作；已经启动的写操作中止后只返回 `DWS_CANCELLED`。

### 目标

任何 DWS 子进程启动前都拒绝已中止的信号，并使用 Node.js `spawn` 的 `signal` 选项处理启动后的中止。已启动的写操作被中止或超时时，返回公开的待核验错误码，不把副作用未知描述为无副作用取消。

### 验收

- 预先中止的信号不会启动 DWS 子进程。
- 读操作中止返回 `DWS_CANCELLED`。
- 已启动写操作中止或超时返回 `DWS_SIDE_EFFECT_UNVERIFIED`。
- 该错误码的序列化结果不含命令、路径、凭据或原始运行时文本。

## BUG-03：安装失败不得恢复未运行的 Gateway

### 当前

运行方式选择已暂存时，OpenClaw 安装失败会进入补偿，并无条件尝试恢复先前 Gateway。先前运行时没有 OpenClaw 二进制或 Gateway 原本未运行时，该调用制造第二条启动失败。

### 目标

运行方式切换前以所选 Gateway 端点记录是否真实运行。补偿只恢复已确认运行的先前 Gateway；否则只回滚已暂存的运行方式和位置状态。

### 验收

- 未运行的先前 Gateway 遇到安装失败时不得调用恢复入口。
- 已确认运行的先前 Gateway 在模式回滚成功后仍可恢复。
- 目录不可写等安装错误保留为主错误，不被后续无效 Gateway 启动替代。

## BUG-04：npm 安装必须使用用户明确选择的目录

### 当前

未选择 OpenClaw npm 目录时，安装器读取 npm 默认全局前缀并把它作为写入目标；缓存目录也可在未选择 npm 安装方式时生效。

### 目标

Native npm 安装只写入用户在设置中选择并保存的 OpenClaw npm 目录。未选择时流程要求配置，不读取 npm 默认全局前缀。npm 缓存仅在该安装方式启用时注入 npm 子进程。

### 验收

- 未配置 OpenClaw npm 目录时，不查询或写入 npm 默认全局前缀。
- 选择的目录不可写时只报告该目录不可写，不建议修改系统 npm 前缀。
- 未启用 npm 安装方式时，npm 缓存目录不传给 npm 子进程。
