# Gateway 设备身份钥匙串提示去重规格

## 当前行为

首次 Gateway 连接的凭据解析可能经过迁移读取和外层读取两条路径，重复请求设备身份引用，
导致系统凭据库提示重复出现。

## 目标行为

1. 同一渲染进程的身份引用查询必须单飞。
2. 查询失败不得缓存失败结果，用户重试仍能重新访问系统凭据库。
3. 私钥和签名结果不得进入渲染进程持久化或缓存。
4. Gateway challenge、device token、配对和权限失败语义保持 OpenClaw 原生契约。

## 验收条件

- 首次无旧凭据启动时，迁移读取与外层读取共享一个身份引用 IPC。
- 身份引用 IPC 失败后，下一次调用会重新发起请求。
- 现有 Gateway 凭据、挑战签名和设备配对定向测试不回归。
- `git diff --check` 和 Emoji 扫描通过。
