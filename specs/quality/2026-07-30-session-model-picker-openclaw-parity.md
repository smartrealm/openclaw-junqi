# 会话模型选择器与 OpenClaw 对齐规格

日期：2026-07-30

## 目标行为

- 桌面会话模型选择器的宽度、栏位比例和最大高度与当前安装的 OpenClaw Control UI 同量级，不遮挡大面积会话内容。
- 供应商图标在会话、共享模型下拉和模型服务设置中来自同一解析器。
- OpenClaw 已提供的供应商使用同源官方图标和别名；未知供应商使用稳定回退。
- 自定义供应商允许设置展示图标，且该数据与 OpenClaw runtime 配置严格分离。
- 当前模型项不可重复选择；切换只在用户保存后提交，不因浏览供应商列表修改会话。

## 约束

- 不按模型名称硬编码供应商、能力或选择逻辑，供应商分组来自 Gateway 返回的模型 ID。
- 不向 OpenClaw `models.providers`、auth profile 或 secret 写入 JunQi 图标字段。
- 图标资源必须随桌面包离线提供，不能依赖外部 CDN。
- 图标加载失败或展示元数据不可读时，模型选择和供应商配置仍可使用。

## 验收条件

- 弹层宽度上限 420px、高度上限 460px、供应商栏 136px，并具有窄窗口约束。
- 52 个随包 SVG 与统一身份解析器一致。
- 新建和已有自定义供应商均可修改图标；清空图标恢复首字母回退。
- 三个模型入口均不再引用旧 `Icon.provider`。
- 相关测试、TypeScript、模块边界、全量测试和生产构建通过。
