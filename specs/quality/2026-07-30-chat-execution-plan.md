# Chat 执行计划规格

日期：2026-07-30

## 目标

把 OpenClaw `update_plan` 结构化工具快照投影为 Chat 中可折叠、可恢复且不干扰消息流的执行计划，同时保留普通 Thinking 和 Tool Call 的既有语义。

## 行为要求

1. 仅接受工具名为 `update_plan` 的合法结构化参数。
2. 至少一个步骤才能形成计划，步骤标题必须为非空字符串。
3. 状态只接受 `pending`、`in_progress` 和 `completed`。
4. 同一快照最多一个 `in_progress` 步骤。
5. 同一响应组只展示最新计划，修订次数和步骤数量变化可见。
6. 当前步骤优先选择 `in_progress`，其次选择首个 `pending`，全部完成时选择最后一步。
7. 折叠态保留当前步骤、序号、总数和整体状态。
8. 展开态展示全部步骤、状态、可选修订说明和步骤数量变化。
9. 折叠偏好仅属于本地视图状态，不写入 Gateway transcript。
10. 历史恢复与实时工具流必须生成一致的计划投影。
11. 设置页面提供自动、始终启用和关闭三种官方配置模式。
12. 配置修改必须使用 Gateway 权威快照、`baseHash` 和 `config.patch`，并保留相邻 experimental 字段。

## 失败关闭

- 参数缺失、状态未知、多个进行中步骤或空计划时不渲染计划卡。
- 不从回复文本、Thinking、工具数量或工具输出猜测计划。
- 计划工具无效时保留普通 Tool Call，以便诊断真实协议漂移。
- 运行中断不能自动把剩余步骤标记完成。

## 验收条件

- 合法快照能够生成稳定步骤 ID 和确定性摘要。
- 重复快照不会增加 revision。
- 修订后的响应组只显示一个最新计划卡。
- 计划工具不再重复显示为普通执行工具。
- 其他工具仍进入既有 `ExecutionProcessGroup`。
- 组件提供 `aria-expanded`、关联区域 ID 和克制的 `aria-live`。
- 简体中文、繁体中文和英文文案完整。
- 四套主题只使用 Aegis token，不包含硬编码品牌色。
- 非默认模型可由用户显式启用计划工具，应用不得静默改写该选择。
