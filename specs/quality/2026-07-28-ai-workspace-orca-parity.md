# AI 工作台 Orca 对照改造规格

状态：代码与自动化完成

日期：2026-07-28

## 目标行为

- AI 工作台保留项目栏、任务栏、中间内容区、右侧活动栏和底部终端的现有结构。
- 右侧 Git 变更面板表示当前 `projectPath` 或任务 worktree 的真实 Git status，不提供无数据依据的任务归属筛选。
- 路径筛选匹配完整仓库相对路径，不区分大小写；空白查询等价于未筛选。
- 面板在可见窗口中立即刷新并按固定间隔刷新；隐藏窗口不发起轮询；恢复可见后立即刷新。
- 同一面板最多有一个 `git_status` 请求在途；在途期间收到的刷新信号合并为一次后续刷新。
- 手动刷新、stage、unstage、discard 和 commit 继续使用同一刷新入口。
- 所有可见文字和 tooltip 使用应用 i18n。
- 全局命令面板必须把 Lucide `forwardRef` 图标作为组件渲染，不能把图标对象作为 React 子节点。
- 智能体展开工作区的文件必须进入与文件管理页相同的 `FileViewer`；不得维护第二套 CodeMirror、读取、保存或格式预览实现。
- Markdown 默认显示渲染预览，并保留 Source/Preview、目录、更多操作、页签菜单和磁盘变更处理。
- 工作区重命名、删除、根目录切换和关闭必须先刷新受影响的共享编辑文档，再同步页签路径。
