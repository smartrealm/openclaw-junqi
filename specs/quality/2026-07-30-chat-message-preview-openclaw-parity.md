# Chat 消息预览与 OpenClaw 对齐规格

## 问题

现有眼睛图标同时承担产物预览和消息预览语义，而且只对部分产物出现，与 OpenClaw 官方消息动作和右侧画布交互不一致。

## 验收条件

1. 非流式且正文非空的助手消息显示统一的 `PanelRightOpen` 图标。
2. 用户消息和空消息不显示该图标。
3. 主聊天点击图标后显示右侧预览分栏，聊天和输入框保持挂载。
4. Quick Chat 点击图标后显示应用内覆盖式预览。
5. 两个入口复用同一个预览内容组件、状态 hook 和预览数据类型。
6. 关闭按钮、标题和可访问名称完整，Escape 可以关闭预览。
7. 预览不执行消息原始 HTML。

## 非目标

- 不在本次接入任意外部网页或本地文件 URL。
- 不把 OpenClaw Gateway Canvas 插件字段写入身份认证或运行时证明结构。
