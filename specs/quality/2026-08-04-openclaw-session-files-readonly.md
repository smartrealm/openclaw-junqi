# OpenClaw 会话文件只读投影对齐规格

## 目标

1. 请求 `sessions.files.list` 与 `sessions.files.get` 时绑定原始 sessionKey、可选 agentId 和当前
   已认证连接。
2. 严格解码官方 sessionKey、文件、浏览器、预览编码和内容字段；返回身份错配、畸形字段、连接切换
   或未知方法必须失败关闭。
3. 仅展示 Gateway 返回的文本与受官方 `image` 预览类型约束的 base64 图片，不将任意本地文件路径、
   URL 或未声明编码当作会话文件内容。
4. 本轮不声明写入、保存、系统打开或本地工作区互操作能力。

## 验收

- client 覆盖列表、读取、请求会话身份、畸形响应和连接切换。
- UI 覆盖加载、空文件、缺失文件、只读文本与官方图片预览。
- 三种已发布界面语言均包含显示文案。
- 文档、TypeScript、测试、构建、官方文档链接和差异检查通过。

## 未验证边界

真实 Gateway 文件内容、远程执行节点与各目标操作系统的实际响应，必须在对应运行时实测；本实现不依赖
平台专属文件 API。
