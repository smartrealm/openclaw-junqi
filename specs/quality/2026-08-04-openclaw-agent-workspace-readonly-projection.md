# OpenClaw Agent 工作区只读投影规格

日期：2026-08-04

## 范围

在 Agent Hub 中以官方 `agents.workspace.list/get` 实现已认证 Gateway 的 Agent 工作区只读浏览。

## 验收条件

- 客户端请求严格使用官方方法名、`agentId` 和工作区相对路径；目录读取可携带官方分页字段，文件读取必须包含非空相对路径。
- 目录和文件响应按官方 schema 严格解析。响应中的 Agent 身份、路径、文件种类、数值和内容编码不符合契约时拒绝结果。
- 每个请求在发送前和响应后校验认证 Gateway 连接身份；方法缺失、断开或连接变化不得产生本机回退数据。
- 只读工作区投影不展示主机绝对路径，不调用 Tauri 文件 IPC，不包含编辑、保存、重命名、删除、上传或系统打开入口。
- Agent 设置中的“打开工作区文件”不再把配置目录传给面板；面板由 Gateway 根据 Agent 身份解析目标工作区。
- 旧的仅供 Agent Hub 使用的本机可写工作区组件及测试被移除；仍被其他本机功能使用的文件系统服务不受影响。

## 非目标

- 不实现任何 `agents.workspace.*` 写操作，因为官方协议未定义该能力。
- 不推断或兼容未知 Gateway 返回字段、未知图片类型或本机路径。
- 不改变 Agent 配置中工作区字段的写入语义。
