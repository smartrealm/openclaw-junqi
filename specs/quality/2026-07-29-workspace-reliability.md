# 工作台可靠性修复规格

日期：2026-07-29

## BUG-WS-01：稳定文件编辑器生命周期

**当前**：活动页签路径参与 `FileViewer` 父场景 key，页签切换会卸载全部文档。

**目标**：文件场景在页签切换期间保持同一组件实例，只由 `FileViewer` 内部选择活动文档。

**验收**：页签切换不改变文件场景 key；预览模式、草稿和编辑器状态保持挂载。

## BUG-WS-02：统一离开前保存事务

**当前**：关闭页签和工作台导航存在同步删除状态路径；flush 后不验证文档是否仍脏。

**目标**：所有会移除编辑文档的操作先等待受影响文档 flush；保存后仍脏、冲突或不可用必须 reject 并保留 UI 状态。

**验收**：单个/左右/其他/全部关闭、返回、新建任务、切换项目和关闭工作区均使用同一异步关闭边界；失败时页签保留并显示错误。

## BUG-WS-03：清理和状态提交保持原子语义

**当前**：进程或工作树清理失败后仍删除任务/标记工作树已丢弃。

**目标**：只有所有必要清理成功后才提交前端状态；失败保留路径、任务和重试入口。

**验收**：合并后删除失败不设置 `worktreeDiscarded`；任务取消或工作树删除失败不调用 `removeTask`。

## BUG-WS-04：工作树终端绑定正确目录

**当前**：显示已有项目终端，恢复 cwd 可覆盖工作树路径。

**目标**：工作树入口显式请求目标目录，并在终端中选择或新建绑定该目录的 shell，不复用错误 cwd。

**验收**：按钮传递 worktree path；已有主仓终端时工作树入口仍激活正确目录的 shell。

## BUG-WS-05：根目录切换可恢复

**当前**：flush 失败后目标根目录丢失，解决冲突不会重试。

**目标**：保存失败时保留待切换根目录并提供重试动作；成功后原子切换根目录和页签状态。

**验收**：错误提示包含重试；重试成功后进入原目标根目录。

## BUG-WS-06：工作台文案统一 i18n

**当前**：工作台存在硬编码中文。

**目标**：用户可见状态、按钮、确认框、空状态和 tooltip 从应用 locale 读取。

**验收**：`zh`、`zh-TW`、`en` 拥有新增键；工作台关键文件不再包含对应硬编码可见文案。

## BUG-TERM-01：终端默认设置原子提交

**当前**：本地偏好先重置，两个原生字段并行独立写入，失败后可能出现部分提交。

**目标**：原生回滚行数与换行偏好通过一次锁定和一次原子文件替换提交；原生成功后才重置前端字体、光标、启动器、预设、Open In 和状态栏偏好。

**验收**：原生失败不会执行本地重置；原生单测证明两个字段由同一设置值恢复；Tauri command 注册和前端参数一致。

## BUG-TERM-02：PTY 打开/卸载竞态收敛

**当前**：卸载时的 kill 可能早于 `open_shell` 注册，迟到结果被忽略并留下后台 PTY。

**目标**：每个打开结果必须明确进入接管或终止分支；组件已清理或返回 run-id 不匹配时按返回的 run-id 再次终止。

**验收**：纯函数行为测试覆盖正常接管、迟到结果和错误 run-id；组件不再静默忽略异常返回。

## BUG-TERM-03：退出时完整停止工作台 PTY

**当前**：退出流程排空注册表后按顺序停止 PTY，任意一次停止失败都会提前返回，使后续句柄失去可达入口。

**目标**：注册表排空后尝试停止每个句柄，并独立执行 provider claim 清理；全部尝试结束后再返回聚合错误。

**验收**：行为测试证明前序停止失败不会阻断后续句柄；命令门面、运行时/注册表、协议缓冲和测试分离，单个 PTY 文件不再混合全部职责。

## BUG-WS-07：Durable Session 跨平台持久化

**当前**：持久化事务无条件打开父目录并 `sync_all`；Windows x64/x86 返回 access denied，所有会话保存、恢复和重置测试失败。

**目标**：命令契约与持久化实现分离；主文件和备份通过可写句柄完成同步，Unix 同步目录元数据，Windows 使用有替换和 write-through 语义的系统 API，不模拟未受支持的目录 `fsync`。

**验收**：同一组 generation/no-op、损坏恢复、证据归档重置和临时文件清理测试必须在 Linux、Windows x64 与 Windows x86 通过；生产代码、测试和 Tauri command 分属清晰模块，单文件不再混合三种职责。

## 未验证边界

- 实际 PTY cwd、进程退出、文件冲突横幅和 Tauri 对话框需要桌面窗口走查。
- 新增 `reset_terminal_settings`，其余 Tauri command 名称、参数和 Rust 序列化契约不变。
- Durable Session schema、Tauri command 名称、参数和 camelCase 返回字段不变；Windows 目录元数据的持久性边界遵循系统公开契约，不声称等价于 Unix 目录 `fsync`。
