# OpenClaw 会话用量范围对齐规格

日期：2026-08-03

## 背景

JunQi 是 OpenClaw 的桌面客户端。Full Analytics 的时间预设必须驱动 Gateway 原生 `sessions.usage` 查询，而不是只请求一份默认范围的数据再把界面标签改成其他范围。

## 约束

1. 请求字段、枚举和值只以 OpenClaw 官方文档、schema 和 handler 为准；不按 package 版本号选择行为。
2. 全局分析请求保留 `agentScope: "all"`，不把当前默认智能体当成全局数据。
3. 7 天、30 天、90 天和全部范围使用官方 `range`；自定义日期使用官方 `startDate`/`endDate`。
4. 响应缺少官方顶层范围或聚合字段、会话行标识非法、行级 `usage` 既不是对象也不是 `null`、费用数值不是有限数时，客户端必须拒绝整次响应。
5. 未知扩展字段可以保留，但不得凭空补齐会话、日期、费用或模型数据。

## 验收条件

- UI 预设到 Gateway 请求参数的映射有纯函数测试。
- 请求保留全局智能体范围，并能表达官方自定义日期边界。
- 当前官方响应可以通过解析，缺少必需顶层字段的旧形状被拒绝。
- 文档明确记录 OpenClaw 负责统计、JunQi 负责请求映射和呈现，以及真实 Gateway/跨平台未验证边界。
