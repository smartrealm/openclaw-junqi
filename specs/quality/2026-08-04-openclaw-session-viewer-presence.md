# OpenClaw 桌面会话查看声明对齐规格

## 范围

本规格约束 JunQi 对 OpenClaw `sessions.viewers.set` 的桌面客户端声明。该 RPC 仅声明当前
Gateway 连接正在渲染的会话，不订阅、创建、修改或持久化任何会话数据。

## 目标行为

1. 仅在已连接、首次安装完成、主桌面窗口获得系统焦点且存在活动会话时，声明该活动会话 key。
2. 主窗口失焦、Gateway 断开、组件卸载或活动会话缺失时，声明空集合或清除本地传输状态。
3. 只能使用 Tauri 主窗口焦点事件和既有 Gateway 连接；不得使用浏览器可见性假设、额外 WebSocket
   或辅助窗口、萌宠窗口冒充会话渲染者。
4. 请求与响应必须严格校验官方 `sessionKeys` 数组。未知方法、权限、断线、连接更换或畸形响应均
   失败关闭，不影响聊天和 history 主链路。
5. 每个 Gateway 连接只保留最后一次确认的声明；请求竞争、连接更换和重复状态必须串行、去重并防止
   旧连接响应更新新连接状态。

## 验收条件

- client 回归覆盖连接更换、串行替换、空声明、畸形响应和未连接关闭。
- 桌面 runtime 回归覆盖焦点、连接、安装完成状态和活动会话对声明集合的判定；Tauri listener
  注册与清理由既有 `subscribeTauriListener` 适配层负责。
- 不新增 Tauri command、浏览器 fallback 或 OpenClaw 本地会话状态。
- TypeScript、相关回归、模块边界、构建和官方文档链接验证通过。

## 非目标

- 不把打开的后台标签、灵动岛、萌宠、Quick Chat 或通知当作 session viewer。
- 不使用该声明推断任务状态、模型输出、消息已读或用户在线状态。
