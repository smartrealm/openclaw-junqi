# OpenClaw 智能体作用域会话侧栏规格

日期：2026-08-09

## 当前行为

- 会话侧栏混合展示所有智能体会话。
- 主会话参与普通活动排序。
- 分类呈现同时依赖 `category`、派生 `groupId` 和日期分桶。
- 新建会话根据当前活动会话推断智能体。
- 侧栏没有分组、排序和“所有会话”入口。

## 目标行为

### BUG-SS-01 · 智能体作用域

- 顶部显示来自 `agents.list` 的智能体选择器。
- 列表只展示当前选中智能体的会话。
- 点击其他智能体的会话后，选择器同步到该会话所属智能体。
- 新建会话明确绑定当前选中的智能体。

### BUG-SS-02 · 主会话固定

- 使用 Gateway 已确认的主会话 key。
- 当前智能体主会话存在时固定为第一行，不参与普通分组和排序。
- 不拼接或猜测不存在的主会话 key。

### BUG-SS-03 · 单一分组来源

- 按自定义分组时，`category` 非空的会话只出现于对应分类。
- `category` 为空的会话只出现于未分组区域。
- 侧栏只读取 OpenClaw `category`，不再读取派生 `groupId` 或日期分桶状态。

### BUG-SS-04 · 官方分组与排序

- 分组依据支持“自定义分组”和“不分组”。
- 排序方式支持“创建时间”和“最近更新”。
- 置顶会话保持独立区域；主会话仍优先于置顶和普通会话。

### BUG-SS-05 · 所有会话

- 侧栏底部固定显示“所有会话”。
- 点击后进入现有 `/sessions` 完整会话管理页。

### BUG-SS-06 · 智能体管理操作

- 智能体作用域菜单同时展示可选智能体、新建智能体和当前智能体设置。
- 新建智能体进入现有 `/agents?new=1` 流程。
- 当前智能体设置进入现有 `/agents?agent=<id>` 详情，不增加本地智能体写入协议。
- 智能体列表暂不可用时仍允许进入新建智能体流程。

### BUG-SS-07 · 稳定创建顺序

- 创建排序不依赖每一行都存在 `createdAt`。
- 首次收到的 Gateway 相对顺序在后续活动刷新中保持稳定。
- JunQi 确认新会话创建成功后，该会话在创建顺序中提升到首位。
- 最近更新排序继续使用 Gateway 返回的活动或更新时间，不与创建顺序混用。

## 验收条件

- 不同智能体的会话不会在当前侧栏混排。
- 切换智能体后列表、新建会话目标和主会话入口使用同一智能体身份。
- 分类会话不会重复出现。
- 两种分组方式和两种排序方式均有行为测试。
- 主会话固定第一且不存在时不生成伪会话。
- `/sessions` 入口支持键盘访问并具有可访问名称。
- 智能体菜单中的切换、新建和设置均支持键盘访问并具有可访问名称。
- 缺少 `createdAt` 的会话仍能按稳定创建顺序展示；已确认的新会话位于普通会话首位。
- 亮色、暗色、窄侧栏、空列表和加载状态使用现有主题 token。
