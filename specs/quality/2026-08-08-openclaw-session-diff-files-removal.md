# 会话变更与会话文件移除规格

## 目标

从 JunQi 产品、前端运行时和 Gateway 客户端门面中完整移除会话变更与会话文件功能，不保留兼容层、隐藏入口、专属状态或无消费者代码。

## 验收条件

- 会话工具栏不出现会话变更、会话文件或统一“更多”入口；分支、会话上下文和会话产物直接可达。
- 源码中不存在两个专属组件、文件编辑器、草稿与预览状态模块。
- Gateway 门面不导出相关类型、错误或方法，也不实例化相关客户端。
- 三种语言不存在专属文案；旧规格、计划和验证记录不再作为当前入口索引。
- 终端 Git 变更、文件管理、Agent 文件和会话产物保持原行为。
- 相关回归、完整测试、Lint、生产构建和差异检查通过。

## 未验证边界

macOS、Windows 和 Linux 桌面窗口中的工具栏密度、Tooltip、键盘焦点、独立面板与窄窗口表现仍需真机验收。
