# 终端与工作台 Chrome 一致性规格

日期：2026-07-30

## 问题

独立终端使用固定深色应用级主题和私有侧栏标题实现，与 AI 工作台的当前主题、尺寸和按钮反馈不一致。

## 验收条件

- 终端与 AI 工作台使用同一个侧栏标题组件和图标按钮组件。
- 展开与紧凑侧栏的标题区域高度稳定，不因页面切换跳变。
- 顶部栏按钮规格一致，终端专属操作能力不丢失。
- 终端不得在应用根节点覆盖 Aegis 主题变量。
- 终端菜单、弹窗和 Agent 状态点使用主题 token，不保留私有固定深色背景。
- PTY、workspace store、标签与 Agent 生命周期无行为变化。
- 回归测试阻止恢复私有标题按钮和应用级固定主题。

## 未验证边界

桌面 WebView 的主题切换、窗口缩放和侧栏动画仍需 macOS 与 Windows 真机验收。
