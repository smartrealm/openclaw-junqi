# 字体设置对齐规格

日期：2026-07-28

## 行为契约

- `uiFont`、`monoFont`、`editorFont` 分别表示界面、终端和编辑器字体栈。
- 空 `uiFont` 使用 JunQi 平台默认界面字体。
- 空 `monoFont` 使用 JunQi 平台默认等宽字体。
- 空 `editorFont` 通过 CSS 继承当前 `monoFont`。
- 字体选择器必须允许搜索系统字体、输入自定义 family、清空选择、键盘上下移动和回车确认。
- 打开选择器时才请求 `get_system_fonts`；同一渲染进程只执行一个并发请求并缓存结果。
- IPC 失败或返回空集合时使用平台回退字体，并向控件暴露回退状态。
- 字体 family 必须规范化并安全引用，不能把任意未处理字符串直接拼入 CSS 字体栈。
