# Windows Gateway 冷启动与默认主会话固定规格

## 范围

- 修复同一回环 Gateway 地址别名导致的冷启动凭据范围误判。
- 以 OpenClaw `agents.list.mainKey` 固定默认主会话页签。
- 不修改 OpenClaw Gateway、会话或智能体的上游语义。

## 验收条件

1. 配置地址为 `ws://127.0.0.1:18789`、持久化地址为 `ws://localhost:18789` 时，连接目标读取
   当前选定运行时 token，且不读取独立设备凭据。
2. 持久化地址指向不同端口、路径、协议或远端主机时，不继承当前选定运行时 token。
3. 收到官方 `mainKey` 后，页签状态、持久化顺序和渲染顺序都把该会话放在第一位。
4. 关闭或重排默认主会话不改变其首位和可见状态。
5. 其他会话仍可关闭，并可在默认主会话之后重排。
6. 相关前端回归测试、类型检查、Lint、构建和 `git diff --check` 通过。
7. Windows 真机未验证时，最终报告必须明确标记，不能声称已完成目标平台实测。
