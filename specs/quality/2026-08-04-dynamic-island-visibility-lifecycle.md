# 灵动岛显隐生命周期规格

日期：2026-08-04

## 目标

修复灵动岛预览或普通活动在关闭后被过期打开请求重新显示的问题，使本地辅助窗口显隐
由主窗口的唯一运行时按最新意图串行收敛。

## 约束

1. `session.observer` 仍只按 OpenClaw 官方协议投影会话摘要；不新增 Gateway RPC、事件、
   字段或会话状态。
2. `DynamicIslandRuntime` 是唯一调用 `open_dynamic_island` 和
   `close_dynamic_island` 的前端所有者。辅助窗口只能发送类型化操作意图。
3. 可见性控制必须容忍异步 `open`、`close`、首次状态同步和快速状态翻转；完成后的窗口
   状态只能由最后一次意图决定。
4. 预览回调必须有代际校验。清除旧计时器后，即使旧回调仍被调度，也不得影响新的预览。
5. 预览停止不修改持久化设置；普通隐藏保留既有关闭 `dynamicIslandEnabled` 的语义。
6. 失败不可伪造成功。IPC 失败只允许结束该轮协调，后续状态改变可以重新协调。

## 验收条件

- 先请求显示、在打开尚未完成时请求隐藏，最终只执行关闭，不发送过期快照同步。
- 快速显示、隐藏、再显示后，最终以最后显示意图同步当前快照，不发生错误隐藏。
- 辅助窗口关闭按钮不再直接调用 Tauri 关闭命令，只回传 `hide` 意图。
- 旧预览回调在新预览开始后执行时不结束新预览。
- 定向回归、`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm verify:openclaw-docs`、Rust
  library 检查和测试、`git diff --check` 通过。

## 非目标

- 不修改 OpenClaw `session.observer` 协议、Gateway 会话生命周期、任务状态或任何远端队列。
- 不承诺未实测平台上的窗口管理器行为。
