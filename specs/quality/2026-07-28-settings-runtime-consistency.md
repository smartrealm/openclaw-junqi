# 设置与运行时一致性规格

状态：代码与自动化完成

日期：2026-07-28

## 目标行为

- 设置页签由 URL 参数作为唯一状态源，切换时不重复播放所有卡片入场动画。
- 设置值不仅持久化，还必须由所有对应运行时消费者读取。
- “设置 > 终端”的字号、等宽字体、光标、回滚行数和 Shift+Enter 必须覆盖工作页终端、工作区任务终端和独立任务终端。
- 通知总开关、声音和免打扰在应用启动后立即同步到通知运行时。
- 用户发起的 Gateway、灵动岛和桌宠操作失败时必须有可见反馈。
- 未实现的配置项、未挂载的重复设置 UI 和未加载的 locale 不得继续作为产品功能保留。
