# 业务引导平台规格

## 目标

在不耦合业务实现、不伪造运行时事实的前提下，为已完成 Setup 且已验证 Gateway 的用户提供可恢复、可扩展的业务上手引导。

## 验收条件

1. 业务引导与 `setupComplete`、OpenClaw Wizard 和安装状态分离，且只在当前 runtime 的身份、认证、配置和模型门禁通过后激活。
2. 引导按会话、模型、Channels、Agent、聊天追溯、协作和工作台模块组织，页面内只显示当前模块相关任务。
3. 任务定义来自声明式注册表；新增模块不要求修改既有模块任务的条件分支。
4. 每个任务以事实适配器提供前置条件、阻塞原因和完成状态；点击导航或业务事件不能单独标记完成。
5. 会话任务覆盖新建、重命名、已有的排序或筛选能力、状态理解和执行追溯。排序任务只在有已验证持久化契约时可用。
6. 模型任务只使用当前 runtime/Gateway 的实时模型和探测结果；不得使用静态模型目录、跨 runtime 缓存或默认值伪装为可用模型。
7. Channels 任务只呈现官方授权和 Gateway 权威绑定结果；不得制造二维码、命令、账号、绑定或完成状态。
8. 引导进度不保存 secret、Provider key、Gateway token、完整 OpenClaw 配置、路径、账号凭据或 transcript 内容。
9. runtime 身份变化或 Gateway 断开会使未完成任务进入明确受阻状态；不会通过旧连接数据继续显示可用。
10. 用户可以关闭、跳过、稍后继续和重新打开任一模块；跳过不等同于业务完成。首次欢迎仅在 `setupComplete` 后的仪表盘自动展示一次，关闭后只能经顶部全局入口显式重开。
11. 所有新增文案覆盖简体中文、繁体中文和英文；内部 ID 默认仅进入技术详情。
12. 任务状态、注册表迁移、Gateway 身份切换、会话完成、模型失败、Channels 未绑定和多语言完整性均有回归测试。

## 失败关闭

- 事实适配器无法确认实体身份、运行时一致性或完成事实时，任务显示受阻或未知，不显示可完成。
- 缺少业务能力或其权限时，任务不提供模拟操作或写入替代路径。
- 业务事件缺少精确实体身份、连接身份或写入确认时，只触发刷新，不改变进度。
