# 钉钉扩展运行时边界整改规格

日期：2026-08-09

## 目标

确保钉钉插件经 OpenClaw 正式工具扩展点执行时，运行时探测可恢复且不向 Agent 暴露无关宿主路径。

## DWS 可执行文件解析

1. 同一时刻的并发解析共享一个 Promise。
2. 解析成功后可以缓存经过 `realpath` 核验的路径。
3. 解析失败后不得缓存 rejected Promise，下一次调用必须重新检查配置路径或 PATH。
4. 子进程仍使用参数数组、`shell: false`、受限环境、超时、输出上限和取消信号。

## 运行时工具输出

1. 只返回可用性、结构化错误、DWS 版本、授权状态、Profile 和安全用户投影。
2. 不返回绝对可执行路径、完整环境变量、凭据或原始配置目录。
3. 不可用时不得声称探测成功。

## 错误投影

1. 只允许已审查的 DWS 错误码和固定安全文案进入工具结果。
2. 详情只允许字段名、匹配数量、退出码、信号和受格式约束的恢复标识。
3. 不返回普通异常原文、子进程 `cause`、原始 DWS 错误文本、路径、参数或凭据。
4. 未知异常和未知错误码统一返回 `DWS_RUNTIME_FAILURE`。

## 验收

- 首次解析失败后创建可执行文件，第二次解析能够成功。
- 成功解析的并发请求复用同一结果。
- 运行状态结果不存在 `executable` 字段。
- 未知异常和已知错误中的非白名单详情不会出现在序列化结果。
- 钉钉插件测试、清单校验和构建通过。
