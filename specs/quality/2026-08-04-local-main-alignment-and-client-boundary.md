# 本地 main 对齐与客户端边界规格

## 问题

本地 `main` 持续前进时，直接按文件版本取舍会重新带入已经被新架构替换的工作区实现，也会保留只在测试中自引用的状态模型。进入改动还包含会损失 JSON 大整数精度的格式化路径和断言源码写法的测试。

## 约束

- 以共同祖先和运行时引用图逐项审查，不以分支名决定覆盖方向。
- JunQi 客户端 UI 可以增强已存在数据的展示，但不得新增或推断 OpenClaw 方法、状态、结果或平台能力。
- JSON 预览必须只读，保留原始数字和字符串字面量；无效、截断和格式化容量不足必须有不同语义。
- 文件类型和路径规则使用共享领域解析，不能复制仅适用于当前系统的路径判断。
- 已被当前生产入口替换且无运行时消费者的页面、reducer、测试和文档必须一起删除。
- 测试执行导出的行为，不读取源码并匹配变量名或 JSX 写法。
