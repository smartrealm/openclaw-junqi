# JunQi 隐私锁规格

日期：2026-08-05

## 当前行为

JunQi 没有应用级隐私锁。主窗口、Quick Chat、独立终端、灵动岛、萌宠、通知和语音在用户离席后仍可能展示或播放敏感内容。Renderer 重载或应用重启不会要求重新验证。

## 目标行为

JunQi 提供完整隐私锁闭环。Native 层拥有锁定状态和认证门禁；用户可使用全局快捷键、托盘或设置立即锁定，也可按系统空闲、休眠恢复和支持的平台会话锁定事件自动锁定。解锁使用 Windows Hello、macOS 系统认证或用户设置的 Native PIN。系统认证不可用时明确降级到 PIN，不存在无验证解锁。

锁定只隐藏和禁止 JunQi UI 操作，不停止已经运行的 OpenClaw Gateway、Agent 或后台任务。

## 验收条件

### Native 状态与持久化

- [ ] Rust 是锁定状态、revision、失败次数和重试期限的唯一权威来源。
- [ ] 启用隐私锁后，应用冷启动和 Renderer 重载不能在认证前挂载敏感业务 UI。
- [ ] 普通配置只保存到 `settings.json`；PIN 验证材料只保存到系统凭据库。
- [ ] 不保存明文 PIN，不向 Renderer 返回哈希、盐、凭据路径、系统账户或原始认证错误。
- [ ] 系统凭据库不可用时，设置或修改 PIN 失败关闭。

### PIN 与认证

- [ ] PIN 至少 6 位数字，密码至少 8 个字符；设置和修改需要确认输入一致。
- [ ] PIN 使用 Argon2id 和随机盐验证，敏感输入在 Native 使用后清零。
- [ ] 连续失败触发基于单调时钟的退避；重载和旧 revision 不能绕过。
- [ ] macOS 使用 LocalAuthentication `DeviceOwnerAuthentication`。
- [ ] Windows 使用 `UserConsentVerifier`。
- [ ] Linux 和系统认证不可用状态明确显示，并保留 Native PIN 解锁。
- [ ] 认证取消、失败、超时、忙碌、策略禁用或设备不可用均保持锁定。

### 多窗口和敏感操作

- [ ] 主窗口和独立终端在锁定时不挂载业务页面。
- [ ] Quick Chat、灵动岛和萌宠在锁定时只显示脱敏状态。
- [ ] 锁定时不能通过拖放创建 Quick Chat，不能新建独立终端、文件预览或截图窗口。
- [ ] 锁定时不能发送消息、启动 OAuth、审批设备、修改 Provider、读取 Token 或执行其他用户敏感操作。
- [ ] 已运行 Gateway、Agent 和后台任务不因锁定而停止。

### 通知与语音

- [ ] 锁定期间的新通知不保存或展示敏感正文。
- [ ] 锁定期间不播放提示音或正文系统通知。
- [ ] 锁定立即停止本地语音输入、TTS 和音频输出。
- [ ] 解锁后不补播锁定期间被抑制的敏感正文。

### 快捷键、托盘和自动锁定

- [ ] 默认全局快捷键为 `CommandOrControl+Shift+L`。
- [ ] 用户可修改、禁用和恢复默认快捷键。
- [ ] 新快捷键注册失败时保留旧快捷键和旧持久配置，并显示冲突错误。
- [ ] 托盘菜单提供立即锁定入口。
- [ ] 设置页提供立即锁定、自动锁定时间、启动锁定、恢复锁定和系统认证状态。
- [ ] Windows 和 macOS 使用平台可信的系统空闲时间；不支持的平台明确显示自动离席检测不可用。
- [ ] 休眠恢复时在窗口内容重新显示前进入锁定。

### UI 和可访问性

- [ ] 设置页新增“安全与隐私”标签，并复用 Aegis 主题 Token、GlassCard、SettingsSwitch 和现有对话框密度。
- [ ] 锁屏支持键盘、焦点管理、Enter 提交、明确 label 和错误状态。
- [ ] 锁屏覆盖亮色、暗色、护眼和暗黑主题，支持窄窗口和 Reduced Motion。
- [ ] 错误在操作附近显示，不使用 `window.alert()`，不显示原始 Native 认证错误。

### 验证

- [ ] 前端和 Rust 回归测试覆盖状态机、重载、旧 revision、凭据失败、退避、快捷键事务、多窗口脱敏、通知和语音门禁。
- [ ] `pnpm lint`、`pnpm test`、`pnpm build`、`cargo fmt -- --check`、`cargo check --lib`、`cargo test --lib` 和 `git diff --check` 通过。
- [ ] Windows Hello、Windows 会话锁定、macOS 系统认证、睡眠恢复和全局快捷键冲突的真机结果单独记录，未验证项不得描述为已通过。
