# 全局轻量视觉系统规格

日期：2026-08-10

## 目标行为

1. 四套主题必须继续提供完整的 Aegis 语义令牌，页面切换主题时不出现固定亮色或固定暗色表面。
2. 普通卡片不得依靠大阴影或位移表达层级；可点击卡片使用边框、背景和文字变化反馈交互。
3. 菜单、弹窗和浮层必须使用主题阴影与主题遮罩，不得使用固定黑色遮罩或通用超大阴影。
4. 默认强调色表面和消息气泡应低于实色按钮的视觉权重，选中状态清晰但不形成大面积高饱和色块。
5. 共享卡片默认圆角不超过 8 像素；对话框和独立浮层可使用 12 像素。
6. 键盘焦点、禁用、加载、错误和空数据状态必须保持现有可用性和语义对比度。

## 非目标

- 不改变用户自定义强调色能力。
- 不改变业务页面的信息架构或 OpenClaw 数据契约。
- 不统一终端 ANSI 色和图表数据色。
- 不新增装饰纹理、渐变背景或营销页动效。

## 验收条件

- `pnpm lint`、主题定向测试、完整测试和 `pnpm build` 通过。
- 修改后的完整文本文件通过 Emoji 扫描。
- 亮色与暗色的共享菜单、对话框、卡片和主要页面不存在明显固定颜色泄漏。
- 未完成的桌面真机视觉检查在验证记录和 `PROJECT_STATUS.md` 中明确列出。
