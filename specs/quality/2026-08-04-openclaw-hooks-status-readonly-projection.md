# OpenClaw Hook 状态只读投影

## 目标行为

1. JunQi 只通过官方 `hooks.status` 读取当前 Gateway 的 Hook 状态，参数必须是空对象。
2. 所有请求必须绑定经认证的 Gateway 连接身份；断线、切换和不支持状态不得保留或采纳旧响应。
3. UI 只显示安全状态投影，不显示本机路径、处理器路径、安装选项、配置检查、环境变量或完整需求详情。
4. UI 只能读取和刷新，不得伪造 Hook 安装、启用、禁用、重载、运行或配置写入能力。
5. 未知响应扩展字段不得进入 JunQi 状态或 UI；已知安全字段结构错误必须失败关闭。

## 验收条件

- `hooks.status` 请求、响应安全投影、method-not-found、断线和连接切换均有回归测试。
- 维护面板显示显式读取入口、可加载或阻塞状态、未知核心触发事件与不可用语义。
- 测试证明本机路径、环境需求和配置检查不进入客户端快照或服务端渲染结果。
- 文档记录权威源码依据、自动化证据和未验证的平台边界。
