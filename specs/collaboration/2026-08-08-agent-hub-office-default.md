# 智能体中心默认办公室投影规格

日期：2026-08-08

## 问题

Agent Office 已在单个协作 Run 的详情中可用，但顶部“智能体”入口默认仍展示与协作任务无直接权威关系的树状、网格和活动视图。用户无法在进入智能体中心时直接看到当前协作运行中的 Agent 分派与执行状态。

## 目标

智能体中心默认展示 Agent Office。该页面复用协作运行时已经维护的权威 Run 摘要和 Run 快照，并允许用户在未归档 Run 间切换或跳转到对应聊天执行详情。

## 约束

1. Office 只消费 `junqi.collab.run.list` 与 `junqi.collab.run.get` 已解码的投影；不得新增 RPC、数据库、任务状态或本地持久化模型。
2. 只有当前选定 Run 的 WorkItem 分派或 Attempt 证明参与的 Agent 才能进入 Office；配置中的 Agent 不构成参与或在线证据。
3. 默认选择最近更新的未归档 Run；用户显式选择仍存在的 Run 时保留选择。
4. Run 列表、快照加载、Gateway 断连、协作插件不可用、读取失败和无 Run 必须分别呈现真实状态，不能伪造办公室成员或成功。
5. 原有树状、网格和活动视图保留为可切换视图；Office 仅改变默认入口，不改变智能体创建、配置、工作区、会话或协作编排语义。
6. 查看详情只执行导航到已有聊天协作详情，不在智能体中心重建协作写操作。
7. 所有新增文案覆盖简体中文、繁体中文和英文；界面复用 Aegis 语义 token 与现有 `AgentOfficeView`。

## 验收条件

- 初次进入 `/agents` 时，Office 是默认激活视图。
- 页面能从 `useCollaborationStore` 读取最近 Run，并对选定 Run 请求完整权威快照。
- 选择器仅提供未归档 Run，且排序为最近更新时间优先。
- Office、空状态、断连、错误和加载状态均有可访问名称与可操作恢复入口。
- Office 成员投影与协作详情复用同一 `AgentOfficeView` 和 `buildAgentOfficeProjection`。
- 既有视图切换不卸载其他视图；没有协作运行时可切换回智能体列表。
- 新增选择规则和默认视图具有定向回归测试。
