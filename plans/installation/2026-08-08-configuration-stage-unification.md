# 首次引导配置阶段统一计划

日期：2026-08-08

## 实施顺序

1. 核对首次引导状态机、Gateway 完成门禁、官方 Wizard 会话与场景动效的当前边界。
2. 让 `gateway-ready` 的呈现阶段与 `configure-openclaw` 一致，但保留其运行时事实语义。
3. 新增配置阶段检查屏幕，复用 `SetupShell`、`StatusPanel` 和既有底栏动作；只调用已有的显式核验操作。
4. 为 `gateway-ready` 和 `configure-openclaw` 提供同一场景键，避免状态交接时重新挂载页面动效。
5. 将默认 `wizard.start` 的协议步骤按类型注册为独立渲染器；渠道跳过说明仍在同一会话中展示。
6. 删除无消费者的独立渠道向导状态、页面、存储、文案、测试和文档。
7. 补齐三套语言资源、回归测试、首次启动流程预览、总览和项目状态记录。
8. 运行定向测试、静态检查、完整测试、构建、差异检查和 Emoji 扫描。

## 不在本轮范围

- 不改变 OpenClaw 官方 Wizard、配置验证、模型验证或渠道配置协议。
- 不自动开始配置核验，不增加本地配置成功标记。
- 不改变 Gateway 启动、运行时选择或返回历史的领域语义。
