# 可选渠道配置实施计划

日期：2026-08-08

## 顺序

1. 核对 OpenClaw 官方 `wizard.start` 的 `setup` 与 `channels` schema、handler 和渠道向导结果。
2. 扩展 JunQi Wizard 客户端的官方 flow 参数，保持会话、超时、取消和运行时范围约束。
3. 抽取共享官方步骤呈现器，新增渠道决策、完成和失败页面。
4. 将首次引导导航从“模型完成后直接 Ready”改为“模型核验后渠道决策，再 Ready”。
5. 补齐中文、繁体中文和英文资源、流程预览、审计、规格和验证记录。
6. 运行 TypeScript、模块边界、定向回归、完整测试、构建、文档链接和差异检查。

## 不在本轮范围

- 不实现渠道插件本身、OAuth、二维码、设备代码或账号路由。
- 不为“稍后配置”增加本地 fallback 或伪造的渠道状态。
- 不把当前 OpenClaw 安装版本写成能力开关。
