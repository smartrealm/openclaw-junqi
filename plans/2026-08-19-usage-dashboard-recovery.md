# 用量仪表盘恢复计划

## 根因

1. 全量用量页的图标辅助函数返回 JSX 源码字符串，卡片把字符串直接渲染成乱码。
2. 仪表盘只要存在任意已知费用就固定展示费用序列，部分未定价供应商的实际 Token 消耗因此不可见。
3. 钉钉插件错误在顶栏以单行截断文本展示，挤压紧凑身份与刷新操作。

## 实施顺序

1. 将 Agent ID 到图标类型的映射拆为无浏览器副作用的纯模块，组件层映射到真实图标组件。
2. 删除导出摘要中的 JSX 占位文案。
3. 增加费用与 Token 指标选择；部分未估价时默认展示 Token 趋势，保留已知费用切换入口。
4. 将长业务错误迁移到接入诊断面板，并保证就绪状态下发生操作错误时面板不会被隐藏。
5. 补充纯函数和状态门禁回归测试，执行静态检查、完整测试、构建和本地打包。

## 验证顺序

1. 图标类型、趋势指标选择和接入反馈门禁定向测试。
2. `pnpm lint`、`pnpm test`、`pnpm build` 与 `git diff --check`。
3. DWS Rust 定向测试、格式检查和库检查。
4. Apple Silicon 未签名应用与 DMG 构建、完整性和架构检查。
