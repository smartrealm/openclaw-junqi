# OpenClaw 会话插件追踪对齐计划

## 完成步骤

1. 对照最新官方 `/trace` 文档、官方主线 ACP 控制面、Gateway 协议和当前安装包，记录 `raw` 值域差异。
2. 审查 JunQi 的会话投影、状态、会话设置客户端和运行时控制，确定原始值保留边界。
3. 建立仅写入 `null|on|off` 的严格领域映射；未知 Gateway 值保留为不可写状态。
4. 接入 `sessions.patch.traceLevel` 的既有 `operator.admin` 串行写入、回执回写、控制面和三语文案。
5. 补充官方值映射、未知值保留、特权写入、会话定向回写和文案回归，执行完整验证和中文提交。

## 非目标

- 不将本地安装包中的 `raw` 视为最新版公开客户端可写能力。
- 不在 JunQi 侧制造、过滤、脱敏或解释插件追踪内容。
- 不通过发送文本指令或普通消息派发隐式改变会话追踪状态。
