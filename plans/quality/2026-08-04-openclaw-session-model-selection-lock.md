# OpenClaw 会话模型选择锁对齐计划

1. 核对 Gateway Protocol、会话行类型、`sessions.patch` handler 和官方测试，确认锁仅禁止包含 `model` 的写入，且恢复默认模型同样属于模型写入。
2. 审查 JunQi 会话列表映射、Zustand `Session`、模型控制面板、模型提交与恢复默认模型调用链，定位丢弃字段和绕过入口。
3. 将 Gateway `true` 投影为会话只读状态；模型列表、恢复默认模型和保存临界区共享同一锁定判定，其他会话覆盖保持独立。
4. 补充领域判定和提交防线回归测试，以及三语可访问文案。
5. 运行定向测试、TypeScript 与边界检查、生产构建、官方链接验证和差异检查；记录真实桌面平台未验证边界后提交中文提交信息。

## 非目标

- 不增加 JunQi 私有解锁、模型权限、模型回退或会话控制协议。
- 不向 Gateway 写入 `modelSelectionLocked`，也不以本地状态覆盖 Gateway 的最终拒绝结果。
