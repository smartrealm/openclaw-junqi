# OpenClaw Session Observer 灵动岛实施计划

日期：2026-08-03

1. 已核对最新版 schema、visibility handler、audience、事件路由和 JunQi 当前灵动岛/萌宠投影。
2. 已新增严格的 visibility 协调器与内存 event bridge，覆盖能力广告、连接围栏、重复和陈旧事件。
3. 已新增用户明确开关，在最小化灵动岛范围内投影原生 Observer headline 和 health。
4. 已同步文档、规格、计划、语言目录，并通过定向、静态、完整测试、官方文档链接验证和生产构建。

## 不做的事情

- 不向 OpenClaw 写入会话、任务、工具结果、Transcript、checkpoint 或 Observer digest。
- 不让萌宠作为 Observer 可见性消费者，不使用 assessment、plan progress 或其他未投影字段。
- 不在未广告、未连接或错误 Gateway 上显示本地模拟状态。
