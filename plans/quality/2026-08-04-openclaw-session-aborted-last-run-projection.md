# OpenClaw 会话最近中止状态投影计划

1. 核对最新官方会话行类型、会话行投影和既有 `sessions.abort` 边界，确认该字段为只读历史状态。
2. 审查 JunQi 会话映射、状态存储、标签页和当前会话栏，确认字段未被现有消费者混用。
3. 新增严格真值投影，在标签页和当前会话栏加入紧凑、可访问的只读提示。
4. 补充真值解析、完整快照清除、三语文案和三层记录。
5. 运行定向回归、类型检查、完整测试、构建、官方链接校验和差异检查后，以中文提交信息提交。

## 非目标

- 不把最近中止状态当作当前运行、错误、恢复条件或任务终态。
- 不修改既有 Stop 检查点、`sessions.abort`、发送队列、语音中断或动态岛逻辑。
