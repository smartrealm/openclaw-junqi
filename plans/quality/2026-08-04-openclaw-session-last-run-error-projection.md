# OpenClaw 会话最近运行错误投影计划

1. 读取最新 Gateway 会话行类型与会话行投影，确认 `lastRunError` 是只读的最近失败或超时摘要。
2. 审查 JunQi 会话列表映射、状态存储、标签页和当前会话上下文栏，确认字段没有现有消费者。
3. 新增严格字符串解析器，将值投影到会话状态；完整刷新缺失字段时清除旧值。
4. 在标签页和当前会话栏加入紧凑、只读、可访问的错误提示，不创建本地恢复或重试操作。
5. 补充解析和会话状态回归测试、三语文案、三层记录，运行全量验证和中文提交。

## 非目标

- 不新增错误生命周期、运行控制、工具状态或 Gateway 写入。
- 不解释错误文本的模型、渠道、权限或副作用含义。
