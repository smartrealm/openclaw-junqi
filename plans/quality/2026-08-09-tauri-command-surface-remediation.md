# Tauri Command 最小暴露面整改计划

日期：2026-08-09

## 根因

历史功能替换后，`generate_handler!` 保留了旧 PTY、旧设置写入、调试日志和仅供 Rust 内部调用的窗口函数。仅按
前端 `invoke` 字面量统计会把动态调用和 Rust 注入页面误判为无消费者，因此必须先建立全量消费者矩阵。

## 实施顺序

1. 解析注册表，扫描生产 TypeScript、TSX、Rust、测试、插件、capability 和文档引用。
2. 将候选项分为“保留注册”“仅保留 Rust 函数”“删除实现”三类。
3. 从注册表和 `#[tauri::command]` 同步移除仅 Rust 内部函数。
4. 删除无消费者实现、专属类型、旧 PTY 模块和专属测试。
5. 运行 Rust 格式化、库检查、受影响回归测试与 diff 检查；随后纳入完整验证阶段。

## 实施状态

步骤 1 至 5 已完成。基线 295 个注册项收束至 272 个，矩阵和删除清单见
`docs/quality/tauri-command-consumer-matrix-2026-08-09.md`。完整前端测试、完整 Rust 测试与生产构建已通过；
三平台真机验证仍未完成。
