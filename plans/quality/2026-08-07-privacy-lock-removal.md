# JunQi 隐私锁能力移除实施计划

## 范围

- 前端启动入口、设置页、通知服务和国际化资源。
- Rust 状态、command 注册、托盘、快捷键及受 guard 影响的桌面 command。
- 对应设计、规格、计划和通知文档中的历史引用。

## 实施顺序

1. 以 OpenClaw 官方协议与现有调用图确认隐私锁仅为 JunQi 本地附加能力。
2. 删除前端锁屏根节点、设置入口、类型、状态、PIN 校验和国际化键。
3. 删除 Rust 锁状态、IPC command、启动恢复 hook、托盘与快捷键，并移除各 command 的 guard。
4. 审查凭据库依赖和其他系统安全能力，保留仍有真实消费者的实现。
5. 清理文档、运行格式化、测试、构建和桌面打包验证。
