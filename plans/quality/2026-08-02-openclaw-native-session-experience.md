# OpenClaw 原生会话体验对齐计划

1. 核对本地旧协议样本、官方当前 schema、权限和运行时 response；不以版本字符串推测字段能力。
2. 新增严格的会话生命周期客户端，移除本地占位会话与随机 session key。
3. 建立原生会话组织客户端，负责 `sessions.patch` 组织字段和 `sessions.groups.*`；仅对明确不支持的旧 Gateway 使用独立桌面仓库。
4. 由 `chatStore` 投影原生状态与兼容状态；会话 identity 变化时重新读取新 identity 的兼容状态。
5. 抽取共享会话操作菜单，接入标签页和侧栏；父会话分叉通过统一的新建入口完成。
6. 按置顶、分组、未分组、归档重组侧栏，并提供分组创建、重命名、删除与移动操作。
7. 补协议、生命周期、组织状态和菜单回归测试；运行 TypeScript、边界检查、测试和生产构建。
8. [x] 收敛 `sessions.list` 读取入口：按当前 schema 分别请求活跃和归档会话，合并投影，并限制旧协议降级条件。
