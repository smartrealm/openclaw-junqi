# OpenClaw 原生会话体验对齐计划

1. 核对当前安装版 OpenClaw 的会话 schema、权限和 server response，禁止从上游未来版本猜测字段。
2. 新增严格的会话生命周期客户端，移除本地占位会话与随机 session key。
3. 建立独立的桌面会话组织仓库，负责 session identity、旧偏好迁移、置顶、未读、归档和分组。
4. 由 `chatStore` 投影组织状态；会话 identity 变化时重新读取新 identity 的组织状态。
5. 抽取共享会话操作菜单，接入标签页和侧栏；父会话分叉通过统一的新建入口完成。
6. 按置顶、分组、未分组、归档重组侧栏，并提供分组创建、重命名、删除与移动操作。
7. 补协议、生命周期、组织状态和菜单回归测试；运行 TypeScript、边界检查、测试和生产构建。
