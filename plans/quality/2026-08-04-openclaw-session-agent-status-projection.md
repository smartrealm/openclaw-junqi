# OpenClaw 会话 Agent 状态投影计划

1. 核对最新会话 patch schema、状态解析器和会话行投影，确认 Gateway 已过滤过期状态。
2. 审查 JunQi 会话映射、标签页和上下文栏，确认没有现有 `agentStatus` 消费者。
3. 新增严格只读解析与会话投影，在标签页和当前会话栏加入紧凑提示。
4. 补充解析与完整快照清除测试、三语文案和三层记录。
5. 运行类型、完整测试、构建、官方链接校验和差异检查后提交中文提交信息。

## 非目标

- 不提供 Gateway 状态编辑、注意事项图标映射、TTL 或本地过期计时。
- 不将会话状态说明解释为任务状态、权限请求、工具失败或当前运行状态。
