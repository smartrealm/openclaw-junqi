# OpenClaw 会话快速模式对齐计划

## 完成步骤

1. 查阅 OpenClaw 官方命令文档、协议类型和 `sessions.patch` 源码，确认会话级快速模式值域和确认响应。
2. 审查 JunQi 的会话列表投影、会话运行时设置、Gateway 特权请求和本地状态回写链路。
3. 在会话领域模型中建立协议值与界面状态的严格双向映射，不接受未记录的状态。
4. 复用 `SessionSettingsClient` 与现有会话设置串行通道写入 `fastMode`，以 Gateway 返回的条目更新目标会话。
5. 在会话运行时控制中呈现四种状态，补齐三种语言文案和窄宽度标签收缩约束。
6. 添加领域映射、Gateway 权限通道与本地状态回写测试，执行静态检查、完整测试、构建和官方文档链接验证。

## 非目标

- 不增加 JunQi 私有的快速模式协议、命令或提供商规则。
- 不将一次发送级的快速模式参数伪装成会话设置。
- 不承诺或模拟模型提供商的性能结果。
