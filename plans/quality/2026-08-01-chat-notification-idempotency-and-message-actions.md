# Chat 通知幂等与消息操作栏实施计划

1. 从 Gateway 已有的运行和消息身份生成通知幂等键，持久 `session.message` 优先透传其显式 `runId`；实时与持久投影都按该运行身份判断是否已经展示。对不含外层运行身份的旧 Gateway 持久镜像，只在同一会话的短时终态正文严格一致时关联到已完成实时运行，再传递到统一通知服务。通用 `onMessage` 只更新聊天状态，不进入通知出口。
2. 在前端进程和 Rust 通知仓库以该键执行幂等写入，并在读取时清理旧版本已产生的同键重复记录；写入返回是否新增，通知服务只在新增时播放或展示。对旧 Gateway 的不同消息 ID 镜像，在同一聊天会话、角色、标题和正文的两分钟窗口内执行受限收敛。无键旧数据仍只保留相邻、且在终态/转录两分钟镜像窗口内重复记录的迁移规则。
3. 将助手气泡操作栏改为正常文档流布局，继续复用共享图标按钮和 Tooltip。
4. 将持久通知命令封装成 repository，并让通知服务、通知中心和终端发布器共用同一出口。
5. 添加 TypeScript、Rust 回归测试，并执行类型检查、格式检查和相关测试。
