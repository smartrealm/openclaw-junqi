# Chat 通知幂等与消息操作栏实施计划

1. 只从 OpenClaw `chat` 流式终态的原生 `runId` 生成通知幂等键。`session.message` 仅更新转录、会话和未读投影，不进入通知出口；通用 `onMessage` 同样不进入通知出口。
2. 前端进程和 Rust 通知仓库按精确键执行幂等写入；写入返回是否新增，通知服务只在新增时播放或展示。删除消息正文、时间窗口和消息内部 ID 的兼容推断与迁移。
3. 将助手气泡操作栏改为正常文档流布局，继续复用共享图标按钮和 Tooltip。
4. 将持久通知命令封装成 repository，并让通知服务、通知中心和终端发布器共用同一出口。
5. 添加 TypeScript、Rust 回归测试，并执行类型检查、格式检查和相关测试。
