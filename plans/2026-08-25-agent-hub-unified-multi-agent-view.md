# 智能体中心统一多 Agent 视图计划

日期：2026-08-25

## 根因

`/agents/live` 是早期独立子智能体监控页。它与智能体中心重复消费 Gateway Session，并在页面内通过 key 正则、定时轮询和自建历史详情维护另一套状态。无子智能体时只显示大面积英文空态，与当前桌面工作台信息架构和主题密度不一致。

## 实施顺序

1. 增加路由行为回归，证明独立监控页仍被注册。
2. 删除 `/agents/live` 路由、页面、特性开关、导航项、标签归属和专属语言资源。
3. 在智能体工具区增加指向 `/agents` 的“协作办公室”入口，并复用现有选中态。
4. 全局检查旧名称、路由和特性键不再有消费者。
5. 执行定向测试、完整检查与桌面视觉验收；无法自动控制的输入法和目标平台边界如实记录。
6. 提交前使用完整未跟踪文件扫描核对新增模块；将树状视图的 DOM 测量提取到独立 Hook，并验证滚动内容坐标与减少动态效果。
