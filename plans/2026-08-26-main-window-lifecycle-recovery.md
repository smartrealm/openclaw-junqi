2. 运行 `cargo fmt -- --check`、`cargo check --lib` 和 `cargo test --lib`。
3. 运行 `pnpm lint`、`pnpm build` 与 `git diff --check`。
4. 扫描本次修改完整文件中的 Emoji。
5. 在当前 macOS 客户端连续验证关闭、最小化、应用隐藏、Dock、托盘和单实例恢复；Windows 与 Linux 保留目标平台实测项。
