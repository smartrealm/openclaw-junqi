# Gateway 管理员权限升级实施计划

1. 以更新后的 OpenClaw 官方主线核对会话参数权限和设备 scope upgrade RPC。
2. 为 scope 升级响应校验、令牌持久化顺序、重连身份围栏和业务重试补充失败回归测试。
3. 在 Gateway 服务边界实现单实例权限升级协调器，不在页面或 Hook 中另建 RPC 状态机。
4. 让统一特权请求器在 scope 拒绝后挂起，并在已核验主连接换代后重新捕获身份。
5. 扩展现有 PairingScreen，使用户可显式发起升级并批准 Gateway 返回的准确请求。
6. 将会话设置的授权错误映射到本地化恢复语义，避免底层英文错误泄漏。
7. 执行定向测试、lint、生产构建、边界检查、差异检查和 Emoji 扫描。
8. 回写 `PROJECT_STATUS.md`，明确自动化与目标平台实测边界。
