# 钉钉主线单平台业务应用 UI 设计

日期：2026-08-08

## 目标

业务应用工作区改为单平台产品界面。当前产品配置默认选择钉钉工作台，页面、侧栏和状态区域只展示该平台；飞书、Google Workspace 等其他适配器不进入默认界面，也不以“即将支持”或不可用卡片占据用户注意力。

单平台不等于删除通用适配器边界。产品配置可以选择一个已注册的业务集成，但一个运行中的 JunQi 版本只能呈现一个集成，不能在页面内切换或同时展示多个平台。

## 当前问题

- 页面顶部先展示三张应用目录卡片，用户进入主线功能前需要进行一次没有业务价值的选择。
- 飞书和 Google Workspace 只有静态展示状态，容易让用户误判为已经进入接入计划或具备可用能力。
- 钉钉作为当前唯一实施主线，没有获得足够明确的身份、接入步骤和能力入口层级。
- 页面标题、侧栏和详情区重复使用“业务应用”“应用目录”等抽象名称，缺少当前平台上下文。

## Langfuse 工作台参考

本轮进一步核对 Langfuse 官方仓库 `017ba00e5080486786029fe68cf03e889320b958` 的实际前端实现，不根据营销页截图推断交互：

- `AppSidebar` 使用可收起图标侧栏，项目与用户上下文留在稳定壳层，页面内容不会重复创建一套产品导航。
- `PageHeader` 使用两个 44px 紧凑行承载面包屑、页面标题、页级控制和子页签，不使用大标题卡。
- `ResizableFilterLayout` 将桌面筛选面板设计为默认约 280px、最小 160px、收起后 40px 的可拖拽轨道；主表格始终获得优先宽度。
- `DataTable` 采用吸顶表头、紧凑行、列宽调整、行选中和固定底部分页，主数据区连续铺满窗口。
- `TablePeekView` 和 `TraceLayoutDesktop` 将详情放在可调整宽度的右侧面板中；面板收起后保留 40px 轨道，列表状态和详情上下文不因开关丢失。

JunQi 只借鉴上述窗口空间和信息层级，不复制 Langfuse 的 LLM 可观测性领域、Web 路由、Tailwind 组件或视觉品牌。钉钉工作台继续使用现有窗口壳层、`aegis-*` 主题和真实 DWS 能力边界。

## 产品配置

当前只有钉钉一个真实消费者，因此生产代码不增加只有一个允许值的平台配置。页面直接呈现钉钉工作台，也不保留飞书、Google Workspace 或“添加应用”的静态入口。

第二个平台只有在具备真实运行时、权限、调用方和验收证据后，才引入受类型约束的单选配置。该配置只能决定当前产品展示哪个已注册集成，不能声明对应运行时已经安装、授权或可用。

## 现有窗口依据

本设计复用当前桌面窗口骨架，不新增网页式外壳：

- `TopBar`：32px 原生覆盖标题栏，macOS 左侧为系统交通灯保留 82px；中部显示 Gateway 状态，右侧保留全局窗口动作。
- `TabBar`：44px 产品页签栏，左侧 204px 品牌区与全局侧栏宽度对齐。
- `NavSidebar`：默认 204px，可切换为紧凑或隐藏状态。
- `StatusBar`：26px 底部状态栏，用于展示当前平台、运行时与只读状态摘要。
- 主窗口默认 1440×900，最小 560×420，允许调整大小。

因此业务应用页不再增加居中最大宽度容器、顶部大标题卡或第二套平台目录。页面内容从全局侧栏右侧开始铺满剩余窗口。

## 信息架构

```text
窗口标题栏
  侧栏显隐 | Gateway 状态 | 全局窗口动作

产品页签栏
  品牌区 | 仪表盘 | 智能体 | 业务应用 | 工具 | 常用命令 | 设置

业务应用窗口体
  左侧栏 204px
    有效工具 | 操作审计 | 接入与授权

  主工作区 minmax(0, 1fr)
    页面标题栏 44px
      当前视图标题 | DWS 当前用户摘要 | 刷新

    有效工具
      阻断状态条，仅在未就绪时显示
      筛选面板 228px，可拖拽，收起为 40px 轨道
      工具表格 minmax(360px, 1fr)，包含搜索与高频筛选、吸顶表头、紧凑能力行和底部摘要
      工具仅按当前 tools.effective 返回的真实业务域分组
      详情面板 382px，可拖拽，收起为 40px 轨道
      当前工具的业务域、风险、Session 状态、参数与运行时契约

    操作审计
      阻断状态条，仅在未就绪时显示
      OpenClaw metadata-only 审计与本地派生关联投影

    接入与授权
      Session | 插件 | Agent 授权 | DWS 身份检查
```

删除页面内的应用目录、平台切换和添加应用入口。若未来产品需要切换主线，通过产品配置生成对应版本，不在业务工作区增加平台选择器。

## 页面布局

### 标题栏与产品页签

标题栏继续承担窗口拖动、侧栏显隐、Gateway 状态、通知和全局辅助入口，不在业务页面复制这些控件。产品页签栏只高亮“业务应用”，不把“钉钉”增加为新的顶级页签。

### 左侧栏

业务应用侧栏直接提供“有效工具”“操作审计”“接入与授权”三个稳定入口。这里不再出现“应用目录”“添加应用”、平台选择控件或占用空间但没有操作价值的说明段落。

侧栏收起时保留三个带可访问名称的图标入口；隐藏时主工作区获得全部宽度。当前视图由 URL 查询参数稳定表达，刷新窗口不会退回页面内部的临时状态。

### 页面标题与接入状态

主工作区顶部只保留 44px 页面标题行，不再复制第二层页签。标题随侧栏入口显示“钉钉业务工作台”“钉钉操作审计”或“钉钉接入与授权”，右侧显示 DWS 当前用户摘要和刷新入口。

工具和审计视图在完全就绪时隐藏 readiness 状态条，把垂直空间留给主内容；出现 Session、插件、Agent 授权、DWS 或身份阻断时，才显示紧凑内联状态和当前可执行动作。

“接入与授权”使用独立工作区集中呈现四项核验：当前 OpenClaw Session、固定校验的钉钉业务插件、当前 Agent 双层授权、DWS Profile 与用户身份。缺少 Agent 授权时必须提供工具策略和插件 `allowedAgentIds` 的真实配置入口；缺少 DWS 时只进入官方安装与登录交接，不伪造安装成功。

### 筛选、能力表格与详情

能力表格是业务页面的主画布，不再使用三张概览卡。桌面端左侧筛选面板默认收起为 40px 轨道，展开后为 228px，且可在 190px 到 320px 间拖拽；中间表格优先获得全部剩余宽度。搜索、业务域和操作效果属于高频浏览操作，放在表格顶部并可一键清除。展开筛选栏只保留业务域的集中浏览，避免同一控件重复出现。租户身份是一次工具调用的参数，只在右侧工具详情中编辑并显式传递，不写入本地持久存储。筛选项只表达界面维度，真实数量和可用状态必须由运行时快照提供。

表格使用紧凑行和吸顶表头，并按当前 `tools.effective` 中真实出现的业务域分组。工具行同时显示业务域、操作效果、风险和 Session 状态，避免用户必须打开详情才能判断风险。不得用固定的“六大能力”或静态数量补齐空数据；未接入运行时前保持真实空态或阻断态。

右侧详情面板默认 382px，可在 300px 到 560px 间拖拽，收起后保留 40px 轨道。选择工具行时原位更新详情，不通过模态框打断浏览；收起或重新打开不能丢失表格筛选、搜索和当前行上下文。业务域、效果、风险和 Session 状态优先展示；工具 ID、DWS canonical path、schema 摘要和原始 JSON 参数收进“高级参数与运行时契约”披露区。

生产实现以[钉钉业务工作台运行时实施设计](dingtalk-business-runtime-implementation-design-2026-08-08.md)为准：能力列表来自当前 Session 的 `tools.effective`，业务页和 Chat 共用 OpenClaw 钉钉插件工具。现有静态 descriptor、Chat bridge 和空 Journal 是待删除的旧实现，不得作为运行时或审计来源。钉钉业务身份仍不得复用 OpenClaw 消息渠道凭据。

## 响应式与可访问性

- 宽窗口使用可拖拽筛选面板、全高能力表格和可拖拽详情面板，不设置人为最大宽度。
- 中等窗口将全局侧栏切为紧凑模式，筛选与详情面板可独立收起为 40px 轨道。
- 窄窗口默认只保留筛选与详情轨道，主表格获得剩余宽度；筛选控件保持在表格工具栏可达。后续生产实现应将两个面板改为覆盖层，不产生页面级水平滚动或不可达按钮。
- 标签、按钮和状态均保留可见焦点、可访问名称和禁用原因。
- 状态同时使用图标与文字，不只依赖颜色。
- 亮色、暗色、午夜和护眼主题均只使用现有 `aegis-*` 语义 token。

## 边界

- 当前生产实现已接入插件状态、当前 Session 的 `tools.effective`、`tools.invoke`、DWS 运行时身份和派生审计投影；这些状态仍不能替代真实 DWS 发布包、真实租户和目标平台验收。
- 当前只有钉钉一个真实实现，不增加空适配器、一值平台配置或兼容层。
- 页面不得把插件已安装解释为工具已进入 Session，也不得把 Gateway 健康解释为 Agent、DWS 或业务身份已授权。
- 接入检查和身份卡只展示现有结构化响应能够证明的字段；上游未返回时显示“待核验”“未返回”或“不可用”。

## 2026-08-09 实施收敛

- 已删除生产页面内部重复的工具/记录页签，将三个视图提升为全局侧栏稳定入口。
- 已增加独立“接入与授权”工作区，并展示 DWS 用户头像、组织、Profile、状态、到期时间和授权域。
- 已将完全就绪状态从工具与审计页面收起，仅保留阻断状态条。
- 已按真实工具业务域分组，技术标识和 JSON 参数移入高级披露区。
- 独立 HTML 预览仅表达布局与状态层级，工具数量与可用状态不构成运行时事实。
