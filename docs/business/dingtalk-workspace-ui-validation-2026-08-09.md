# 钉钉业务工作台 UI 收敛验证

日期：2026-08-09

## 当前行为

- 业务应用左侧栏直接提供“有效工具”“操作审计”“接入与授权”三个稳定入口，页面内部不再复制页签。
- 工具与审计视图只在阻断、错误或待核验时展示 readiness 状态条；完全就绪后把空间交还主内容。
- 接入工作区分别展示当前 Session、固定钉钉插件、Agent 双层授权和 DWS 身份核验。
- DWS 身份卡只展示运行时返回的头像、用户、组织、Profile、状态、到期时间和授权域；缺失字段保留未返回语义。
- Agent 授权阻断状态提供 OpenClaw 工具策略和插件 `allowedAgentIds` 配置入口，最终状态仍由当前 Session 的 `tools.effective` 核验。
- 工具表格按真实工具的业务域分组；技术标识、DWS canonical path、schema 摘要和 JSON 参数位于高级披露区。
- HTML 设计预览中的工具行明确标记为结构示例，不表示工具已进入当前 Session。
