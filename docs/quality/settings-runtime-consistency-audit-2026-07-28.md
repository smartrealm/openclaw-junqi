# 设置与运行时一致性审计

日期：2026-07-28

范围：设置页、设置持久化、通知运行时、工作区/独立任务/工作页终端、应用语言

## 结论

设置页此前存在三类不一致：切换页签会让所有卡片重复播放入场动画；部分设置只写入存储而没有在应用启动时同步到运行时；独立任务终端和工作区任务终端没有完整消费终端设置。另有一个未实现的语音唤醒配置区和一套未挂载的旧设置弹窗，继续保留会制造无效设置与双实现漂移。

本轮统一了设置页状态、通知运行时和终端消费者，删除了无实现入口与旧实现。没有改变 Tauri command 名称或 Rust 序列化契约。

## 发现与处理

| 领域 | 审计时行为 | 当前行为 |
| --- | --- | --- |
| 页签切换 | 页签内容卸载后重建，嵌套 `GlassCard` 全部重复执行错峰入场动画；页面内定义的开关组件会随父级渲染产生新类型 | 设置内容区关闭卡片入场动画，页级过渡保留；当前页签只由 URL 参数决定；页面与终端共用模块级稳定开关组件 |
| 终端字号与字体 | 工作页终端已消费；直接进入 `/agent-run` 会使用组件默认值 | 工作页、工作区、独立任务路由统一读取设置 store，并对已打开终端实时更新 |
| 终端光标与回滚行数 | Shell 终端消费；任务终端漏用光标，独立任务路由漏用回滚行数 | Shell、工作区任务和独立任务终端统一消费；已打开终端立即更新 |
| Shift+Enter | Shell 与任务终端各自监听 Tauri 设置 | 保留既有 IPC 契约，并继续响应同文档设置变更事件 |
| 通知 | 设置值持久化，但通知单例启动时仍保留默认值；只有手动切换后才同步 | 根运行时持续同步总开关、声音和免打扰；测试按钮在被策略阻止时禁用 |
| Gateway 编辑 | URL 草稿可能在外部状态变化后陈旧；保存/重连异常可能形成未处理 Promise | 未编辑时跟随 store；保存、测试和重连共用可见失败状态 |
| 存储 | 管理文件统计在设置页挂载时就查询 | 仅进入“存储”页签后查询 |
| 桌宠与灵动岛 | 个别窗口命令吞掉失败 | 可见操作失败会进入已有错误提示或通知通道 |
| 语音唤醒 | 展示未实现的 Picovoice 凭据与参数，并把 AccessKey 写入前端存储 | 删除未实现入口、字段和历史本地键；不再在前端持久化该 secret |
| 设置实现 | 未使用的 `AppSettingsDialog` 与正式设置页并存 | 删除未挂载旧实现和对应无用 store 状态 |

## 语言边界

JunQi 当前应用语言是 `zh`、`zh-TW`、`en`。原 `src/locales/ar.json` 没有被 i18n 加载，也没有出现在语言选择器中，因此不是可用产品语言；本轮删除该孤立资源及兼容分支。

按项目安装的 OpenClaw `2026.7.1` 文档核对：

- `docs/cli/onboard.md` 的向导语言只有 `en`、`zh-CN`、`zh-TW`；
- `docs/web/control-ui.md` 的浏览器 Control UI 支持 `ar`，并由 Control UI 自己保存语言偏好。

所以 OpenClaw Control UI 支持阿拉伯语，不代表 JunQi 应用或 OpenClaw onboarding 向导支持阿拉伯语。删除 JunQi 的未加载 `ar.json` 不影响 OpenClaw Control UI。
