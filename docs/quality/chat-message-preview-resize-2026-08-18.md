# 消息预览宽度调整

日期：2026-08-18

## 当前行为

主会话中的消息预览原先固定为 `min(46%, 720px)`，用户不能调整正文与预览之间的边界。Quick Chat 使用覆盖式预览，不存在并排栏宽度。

## 实现与边界

- 非覆盖式消息预览在左边界提供可拖拽分隔条；拖向左侧增大预览，拖向右侧缩小预览。
- 宽度下限为 340px，上限为父容器的 70% 且不超过 1100px，防止正文区域失去可用宽度。
- 分隔条支持左右方向键微调、按住 Shift 的大步调整、Home/End 到边界，以及双击恢复 720px 默认宽度。
- 窄窗口沿用现有 `max-md` 覆盖式面板，因此不显示不可用的分隔条。
- 该宽度是当前打开预览的局部 UI 状态，不写入 OpenClaw、Gateway 或本地业务持久化。

## 验证

- `chatSidePanelResize.test.ts` 覆盖默认值、容器上限和最小最大宽度收敛。
- `chatMessagePreviewUi.test.ts` 与 `pnpm lint` 通过。
- 已重新生成 macOS ARM64 `.app` 并启动新进程；该构建仍受本地 updater 私钥缺失限制，不作为正式发布包。
