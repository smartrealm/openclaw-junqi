# 用量仪表盘恢复记录

日期：2026-08-19

## 官方依据

- OpenClaw Gateway 协议将 `usage.cost` 定义为日期范围内的聚合费用用量，将 `sessions.usage` 定义为会话级用量与聚合结果；两者均支持全部 Agent 范围。
- OpenClaw Token 用量文档说明，只有活动模型已配置价格且供应商返回用量元数据时才会持久化可估算的 `usage.cost`。价格缺失时应展示 Token 和缓存明细，不能补造费用。

## 已确认问题

- 全量用量页的 `getAgentIcon` 返回类似 `<Bot size={14} ... />` 的普通字符串。卡片直接渲染该字符串，窄容器只露出 `size`、`weight`、`strokeWidth` 等属性碎片。
- 仪表盘已经读取 OpenClaw 每日 Token 字段，但只要最近窗口存在任意已知费用就选择费用图。大量调用未定价时，用户无法直接看到真实 Token 趋势。
- 钉钉插件操作错误被放在顶栏并强制单行截断，既缺少完整上下文，也挤压身份区。

## 当前行为

- Agent ID 只派生有限图标类型，组件层将类型映射为真实 Lucide 图标；不再保存或渲染 JSX 源码字符串。
- 仪表盘支持“费用”和“Token”切换。部分调用未定价且存在多日 Token 记录时默认显示 Token；费用视图仍只展示 OpenClaw 返回的已知估价。
- 单日 Token 记录显示汇总，不伪造趋势。
- 全部未定价与部分已估价由同一互斥分类函数决定，不会在同一区域同时显示两种相互矛盾的提示。
- 钉钉操作错误和授权结果在接入诊断面板内完整显示；顶栏只保留紧凑身份和刷新。

## 自动化验证

- 图标映射测试验证所有返回值都是可映射类型，不包含 JSX 标记或属性文本。
- 趋势指标测试验证部分未估价时自动选择 Token，并允许用户显式选择已知费用。
- 接入反馈门禁测试验证就绪状态下发生错误或产生授权结果时不会隐藏诊断面板。
- 费用提示测试覆盖全部未定价、部分已估价、完整估价和无用量四种事实组合。
- `pnpm lint`、完整 `pnpm test` 和 `pnpm build` 通过。
- `cargo fmt -- --check`、`cargo check --lib` 和 `cargo test --lib` 通过；Rust 645 项通过，1 项会修改当前用户 Keychain 的既有测试按设计忽略。
- Apple Silicon 本地验证包构建成功；应用二进制为 Mach-O arm64，应用与构建版本均为 3.1.2，DMG 经 `hdiutil verify` 核验有效。

## 未验证边界

- 尚未在亮色、暗色和窄窗口下人工核对费用与 Token 切换、图例、提示框和 Agent 卡片。
- 尚未用真实混合定价数据验证费用曲线与 Token 曲线的连续切换。
- Windows、Linux 和 Docker 只消费相同 Gateway 结构化响应，本轮未做目标平台真机视觉验收。
- 当前 DMG 使用 `--no-sign` 构建，仅有链接器生成的 ad-hoc 标记，没有 Developer ID 签名或公证。
