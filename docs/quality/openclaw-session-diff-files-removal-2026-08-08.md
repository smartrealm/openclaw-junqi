# OpenClaw 会话变更与会话文件移除记录

日期：2026-08-08

## 当前行为

JunQi 会话工具只保留当前交互中仍有明确消费者的分支、会话上下文和会话产物，三项能力均作为独立直接入口。会话上下文栏不再提供会话变更与会话文件入口，也不再注册 `sessions.diff`、`sessions.files.list`、`sessions.files.get` 或 `sessions.files.set` 的客户端门面。

终端 Git 变更、文件管理页、Agent 工作区、Agent 引导文件和会话产物属于独立业务，继续使用各自现有的 Tauri 或 OpenClaw 契约，本次不调整。

## 删除范围

- 删除会话变更与会话文件两个界面组件及其专属编辑器、草稿、预览判别状态。
- 删除两个专属 Gateway 客户端、公开类型、实例和门面方法。
- 删除专属测试、三种语言文案和已失效的实现规格、计划与验证记录。
- 会话工具栏回归明确禁止这两个入口和无消费者的统一“更多”菜单重新出现。

## 技术决策

OpenClaw 上游是否支持相关 RPC 与 JunQi 是否需要提供该产品入口是两个问题。JunQi 作为客户端可以不消费上游能力；既然当前产品不再需要这两个入口，就不保留无消费者协议封装、兼容层或隐藏代码。

## 验证

已通过 59 项 Gateway 聚焦回归、`pnpm lint`、完整 `pnpm test`、`pnpm build` 和 `git diff --check`。生产构建不再生成两个专属组件或 Gateway 客户端的独立模块；测试只保留一条入口缺失回归。

macOS 桌面包的构建与校验结果回写到根目录 `PROJECT_STATUS.md`。Windows 与 Linux 未执行真机视觉验收。
