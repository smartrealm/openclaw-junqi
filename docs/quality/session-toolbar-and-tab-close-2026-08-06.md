# 会话工具栏与标签关闭收敛

日期：2026-08-06

## 依据与现状

`SessionContextBar` 同时存在两个会话产物入口：旧入口只能下载，`SessionArtifactsControl` 可预览和下载。准星入口只写入 JunQi 本地焦点状态，未提供当前会话工作流所需的直接业务操作。

`chatStore.closeTab` 只是更新 JunQi 的桌面标签投影，不调用 OpenClaw 删除会话。此前 `MAIN_SESSION` 的特判错误地把“禁止删除规范主会话”扩展成了“禁止关闭主会话标签”。

## 目标行为

- 删除重复的旧会话产物入口和无直接业务操作的本地焦点入口。
- 删除全局技能、全局工具配置和全局活动入口；这些入口不属于当前会话操作。
- 保留具备明确 OpenClaw 会话能力或已有工作台入口的操作：当前会话实际工具、浏览器控制、分支、检查点和制品。
- 任意已打开会话标签均可关闭；关闭最后一个标签时回退到可见的规范主会话。
- 删除操作仍不得删除规范主会话。

## 验证边界

需要在桌面制品中验收工具栏密度、图标语义和主会话关闭后的标签回退。

## 当前实现与验证

- `SessionContextBar` 当前只保留当前会话工具、浏览器控制、分支、会话上下文和会话产物入口；五项能力均直接可达，会话伴侣、会话变更、会话文件和统一“更多”外壳已在后续收敛中移除。
- `ChatTabs` 为包括规范主会话在内的所有已打开标签提供关闭按钮和中键关闭；`chatStore.closeTab` 只更新本地标签投影，
  `removeSession` 仍通过 `isAgentMainSession` 禁止删除规范主会话。
- `src/stores/chatStore.test.ts` 新增主会话标签关闭回归，确认 Gateway 会话记录保留并切换到剩余标签。
- 已通过 `pnpm lint`、完整 `pnpm test`（前端 2806 项、脚本 243 项）、`pnpm build`；完整测试仍有既有第三方
  SSR `useLayoutEffect` 警告，但命令成功结束。
- 已按会话工具栏调整对应的提交重建并安装 macOS ARM64 `.app`；头像视觉调整发生在其后，尚未重新安装，真实视觉验收和 DMG 重建仍待完成。
