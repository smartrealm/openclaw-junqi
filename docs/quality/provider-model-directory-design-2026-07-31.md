# 提供商模型目录设计记录

## 依据

- `src/pages/ConfigManager/ProviderModelEditor.tsx` 已使用固定列的模型编辑表，能够编辑模型别名、图片输入能力和默认路由。
- `src/components/shared/provider-identity/ProviderIcon.tsx` 是提供商图标的唯一实现：内置提供商使用应用打包的官方 SVG，自定义提供商使用本地持久化的受限标记。

## 原行为

“模型与别名”概览使用单张固定列宽表格，每一行重复展示提供商图标与名称。该表格把 `config.provider` 对象键当作表头字符串，并引用未定义的 `config.alias`、`common.actions`，导致部分语言直接显示错误或翻译键。固定最小宽度还要求窄窗口横向滚动。

## 目标行为

只调整“模型与别名”下方的目录，不改变提供方配置、默认模型或路由控制：

- 先按模型引用中的提供商命名空间分组，再按提供商和模型 ID 排序。
- 提供商图标、名称、ID 和模型数量只显示在分组标题，不在每一行重复。
- 宽窗口使用模型、别名、用途和操作四列紧凑展示。
- 窄窗口改为自然换行的单列条目，不依赖固定最小宽度和横向滚动。
- 主模型和图片模型以文字加图标共同表达；未分配用途时显示明确文本。
- 操作继续保留设置主模型、设置图片模型和移除模型，增加键盘焦点样式与可访问名称。
- 目录使用独立字符串翻译键，避免把提供商名称对象当作表头。

模型详情和别名编辑仍由提供商配置内的 `ProviderModelEditor` 负责。

## 模型定价维护补充

OpenClaw 2026.7.1-2 的运行时 schema 允许在 `models.providers.<provider>.models[]` 中维护 `cost`，平面单价字段为 `input`、`output`、`cacheRead` 和 `cacheWrite`，单位是美元每百万 Token。提供方展开后的模型编辑器增加独立的可视化定价区域，支持输入零值和小数、应用修改以及清除平面定价；非法负数和非有限值在表单内阻止提交。定价只写入 provider model，不复制到 `agents.defaults.models`。

该金额供 OpenClaw 根据 transcript usage 做本地估算，不代表供应商正式账单。若模型已经配置 `tieredPricing`，修改平面定价时保留该字段；高级 JSON 编辑器不再重复展示 `cost`，避免两个入口产生覆盖竞争。

本机 `vllm/gpt-5.6-sol` 的平面定价依据 Sub2API 当前价格目录换算为每百万 Token：输入 5、输出 30、缓存读取 0.5、缓存写入 6.25。其他模型没有足够可靠的实例级价格依据时不写入猜测值。
