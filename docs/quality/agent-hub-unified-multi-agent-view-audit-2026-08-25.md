# 智能体中心统一多 Agent 视图审计

日期：2026-08-25

## 现象

侧栏“多智能体视图”打开 `/agents/live` 后，在没有子智能体 Session 时展示英文标题、英文空态和几乎占满工作区的空白画布。该页面没有解释与智能体中心办公室或持久协作运行的关系，也没有提供可执行下一步。

## 根因

问题不是缺少三条中文翻译，而是仓库同时保留了两套多 Agent 信息架构：

- 智能体中心已经消费 Agent、Session、原生子智能体运行和协作运行，并提供办公室、树状、网格和活动视图。
- 独立 `MultiAgentView` 再次消费相同 Session，在页面内用正则识别子智能体 key、每五秒轮询历史、解析任意内容并维护独立详情与空态。

这条旧路径重复定义数据选择、生命周期和展示语义，且页面层直接承担 Gateway 历史读取。继续翻译或美化只会维持双轨。

## 修正

- 删除 `MultiAgentView`、`/agents/live` 路由和 `liveAgents` 产品特性。
- 删除旧导航名称、语言资源和标签归属。
- 智能体工具区提供“协作办公室”入口，直接进入 `/agents`，并使用既有 `SidebarRow` 选中态。
- 原生子智能体与持久协作运行继续保持不同权威来源，但统一在智能体中心呈现。

## 验证边界

路由回归可证明独立页面不再注册，静态检查可证明旧特性和引用被删除。智能体中心当前无真实子智能体运行时的办公室空态、窄窗口、深色主题和连续活动变化仍需在真实 Tauri 客户端验收。

## 提交前代码审查补充

严格审查发现智能体树新增的连线几何模块与测试未进入 Git 变更集；页面已经导入该模块，遗漏提交会让其他环境直接构建失败。两份来源文件及后续提取的 DOM 测量 Hook 已纳入同一提交范围。

原实现只用滚动容器的可见矩形作为 SVG 宽高，内容超过视口后连线会被截断；滚动状态下重新测量还会丢失滚动偏移。修正后，纯几何模块把视口、滚动偏移和完整内容尺寸转换为统一内容坐标系，DOM 测量与 `ResizeObserver` 生命周期收敛到独立 Hook，避免继续扩大两千行以上的 `AgentHubPage`。主到 Agent、Agent 到 Worker 的连线仍只消费已渲染卡片矩形，不增加会话或调度语义。

装饰性流动圆点现在读取系统减少动态效果偏好；开启后只保留静态关系线。办公室运行总览继续复用 `aegis-border`、`aegis-surface-solid`、`aegis-primary`、文本状态 token，以及现有 `AgentOfficeCharacter`、`AgentOfficeFurniture` 和 `SidebarRow`，没有新增平行主题。
