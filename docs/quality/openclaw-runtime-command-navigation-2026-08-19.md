# OpenClaw 运行时命令导航

日期：2026-08-19

## 上游依据

OpenClaw Gateway 官方 `commands.list` 是按 Agent、Provider、Scope 返回运行时命令目录的 `operator.read` 方法。官方协议明确 `category`、`textAliases`、`nativeName` 与参数详情都由 Gateway 返回；JunQi 不维护本地命令注册表。

## 当前行为

运行时命令页和左侧导航分别读取当前会话 Agent 的 `commands.list` 目录，并以 Gateway 返回的 `category` 分组。导航项的命令数量和类别均来自该响应；没有 `category` 的条目显示为“未分类”。

命令目录复用应用外壳唯一的路由滚动容器实现双向 Scroll Spy：

- 用户滚动右侧目录时，以粘性页头下方的可见锚点解析最后一个已经越过锚点的真实分组，并用替换式 hash 导航同步左侧选中项。
- 左侧选中项超出侧栏视口时只滚动到最近可见位置，不改变右侧目录的滚动状态。
- 点击左侧类别时，右侧按实时页头高度平滑定位；减少动态效果模式改用即时定位。
- 程序定位尚未稳定时暂停滚动观察，避免经过中间分组时产生高亮抖动或覆盖目标类别。
- 目录顶部保持“当前目录”选中；滚动到底部时，即使最后一个分组较短，也明确选中最后一个真实分组。

滚动和点击都只改变本地导航投影，不调用命令、不改变会话，也不将类别推断为命令可执行性。

连接断开、目录读取中、Gateway 不支持该方法或返回不可验证内容时，左侧保留对应的真实状态说明，不显示本地伪造的类别或命令。

## 验证

- 分组回归测试覆盖 Gateway 已返回类别和缺失类别的保留行为。
- Scroll Spy 回归覆盖页头锚点前后的活动分组、短尾分组的底部收敛，以及类别 hash 与目录顶部之间的转换。
- 定向回归 4 项、完整 `pnpm test`、`pnpm lint`、`pnpm build` 和 `git diff --check` 均通过；脚本测试
  238 项无失败，生产构建转换 9303 个模块。

## 未验证边界

- 本次尚未在不同 Gateway Provider 和所有命令类别上完成真机连续滚动、点击定位与侧栏自动可见验收；类别和数量仍完全由实际 `commands.list` 响应决定。
- 自动化验证活动分组判定和 hash 契约，不等同于亮色、暗色、窄窗口、键盘焦点与减少动态效果的真实视觉验收。
