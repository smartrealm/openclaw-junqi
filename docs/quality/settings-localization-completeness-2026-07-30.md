# 设置页面多语言完整性审计

日期：2026-07-30

## 依据与根因

设置页面通过 i18next 的默认点号分隔规则读取嵌套键。六个标签翻译被存成
`settings` 对象下的 `tab.appearance` 等扁平属性，运行时无法解析，只能使用组件中的
默认文本。

终端设置、Gateway 生命周期、Gateway 日志、连接测试、检修协作闸门和萌宠文字缩放等
后续功能只增加了源码默认值，没有同步 `zh`、`zh-TW` 和 `en` 目录。终端状态栏标签还
直接读取英文常量，完全绕过 i18n。

## 修复

- 将所有设置标签并入 `settings.tab` 嵌套对象，删除无法解析的扁平属性。
- 补齐三种语言中的静态设置键和动态状态键。
- 终端状态项、Gateway 生命周期、运行模式、检修分类、强调色和萌宠皮肤统一通过稳定
  标识读取目录。
- 移除本次涉及的源码默认文案与重复英文标签常量。
- 将设置页裸露的时间单位纳入语言目录。
- 清理本次写入语言文件中已有的图形字符，改为纯文本。

## 验证

- 新增设置页面翻译契约测试，扫描设置主页面和全部设置子组件。
- 测试按 i18next 实际嵌套规则检查 `zh`、`zh-TW` 和 `en`，不接受扁平点号键。
- 定向测试通过：66 项通过，0 项失败。
- `pnpm lint` 通过。
- `pnpm test` 通过：前端 1916 项、脚本 224 项，共 2140 项，0 项失败。
- `pnpm build` 通过。
- `git diff --check` 在最终写入后复核。
