# 终端与工作台 Chrome 一致性记录

日期：2026-07-30

## 依据与原有行为

独立终端和 AI 工作台必须保持不同的 PTY、workspace store 与会话生命周期，但它们都位于 JunQi 桌面产品外壳中，侧栏标题、顶部按钮和主题语义应当一致。

原实现把 `terminal-kooky-app` 挂在应用根节点，通过固定深色变量覆盖顶部栏、全局侧栏和终端侧栏。终端侧栏标题栏另有一套 48px 内联实现，AI 工作台使用 56px 标题栏和独立按钮样式。切换页面时会产生颜色、尺寸和交互反馈跳变。

## 目标行为

- 终端和 AI 工作台共用 `WorkspaceSidebarHeader` 与 `WorkspaceChromeIconButton`。
- 侧栏标题栏统一为 56px，图标按钮统一为 28px。
- 顶部栏的侧栏、Agent 和通知按钮使用同一 chrome 控件。
- 终端保留命令搜索、外部应用、Agent 面板、通知和保持唤醒能力。
- 终端 chrome 使用当前主题 token，不再覆盖应用根节点颜色。
- PTY、工作区持久化、终端标签和 Agent 运行 ownership 不变。

## 实现边界

共享组件只负责表现和可访问语义，不持有业务状态。终端和 AI 工作台仍分别拥有自己的 sidebar mode、数据源、操作回调和生命周期。

## 验证范围

自动化覆盖共享组件的可访问名称和稳定尺寸、两边的共同引用、根节点固定主题清理，以及原有终端导航契约。
