# 首次安装底部操作区响应式修复

## 依据

储存位置步骤在执行 `configure_storage` 时把真实进度文案显示在主操作按钮。窄窗口中，回退按钮、次要操作和较长的主操作文案会在同一横向区域争夺宽度，截图显示为两个操作区域视觉重叠。

## 修复

`SetupShell` 在小于 `sm` 的窗口使用纵向操作区：回退区域独占第一行，次要与主操作按纵向排列，主操作占满该行。渲染结构以独立的回退区、操作区和主操作锚点表达这三个区域；`sm` 及以上保留现有的左右操作布局。该变更只影响布局，不改变储存配置、回退或单飞事务的状态契约。

## 验证

- `src/components/setup/SetupFlowPanels.test.tsx` 渲染加载态主操作、次要操作和回退操作，验证三个区域独立存在。
- `pnpm test`、`pnpm lint`、`pnpm build` 和 `git diff --check` 通过。
- 浏览器自动化连接在本次环境中不可用；需要在实际桌面窗口的窄宽度下完成一次返回储存步骤和一次储存确认的人工验收。
