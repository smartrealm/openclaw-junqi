# 首次启动往返导航修复验证

日期：2026-08-08

## 验证对象

本记录验证以下链路：

1. 环境检测页点击下一步进入数据位置页。
2. 数据位置页点击上一步返回环境检测页。
3. 环境检测页再次点击下一步，仍能进入数据位置页。
4. 步骤切换只保留当前页面的运行生命周期，并提供不阻塞导航的方向入场动效。

问题原因见[首次启动往返导航审计](setup-round-trip-navigation-audit-2026-08-08.md)，目标契约见[修复规格](../../specs/installation/2026-08-08-setup-round-trip-navigation.md)，实施范围见[修复计划](../../plans/installation/2026-08-08-setup-round-trip-navigation.md)。

## 实现结论

- `SetupStepTransition` 不再保留退出页面，只为当前步骤页执行方向入场。前进从左向右收敛，返回从右向左收敛；减少动态效果偏好下立即呈现。
- `useSetupEnvironmentReview` 使用 `idle`、`navigating`、`redetecting` 三态同步驱动原子单飞保护和渲染状态。
- 环境检测页的上一步、重新检测和下一步使用同一个禁用判据。
- 步骤进入时重置环境动作状态，因此返回环境检测页后可以再次执行下一步。
